## 发布设置建议

| 项 | 建议 |
|---|---|
| 封面 | 用 `cover_3x4.png`（1080×1440）。抖音上传封面选"上传封面"，竖版在信息流里占得更满 |
| 时长 | 42 秒，完整发。前 3 秒是巨眼特写，画面信息量大，能拉住划走 |
| 发布时间 | 20:00–22:30。这类情绪动画在晚间完播率明显高于白天 |
| 标题栏 | 单独一栏别再重复文案，写：`42 秒，100 个鼓点，13 个世界` |
| 音乐 | **必须注意**：用原曲做 BGM 会触发版权识别，可能被限流或收益归版权方。想投流/商用，换成已授权的翻唱版或纯音乐改编版 |
| 二次分发 | 把 0:27–0:31（抱心 → 心炸 → 巨眼掉出他）单独剪 4 秒发一条，钩子最强 |
