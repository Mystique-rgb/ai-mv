# 《幻听》MV 分镜提示词 v5 ｜ 玻璃上的第二个人（80 年代赛璐璐）

> 画风：**80 年代赛璐璐动画**（lemo-opuscar `styles/cel-anime-80s`，STYLE.md 为硬约束）
> 结构：一个 80 年代的小房间、一扇雨窗、一台录音机、两把椅子。整首歌里，玻璃上一直有第二个人在跟他一起唱——只有他自己知道那面玻璃是空的。
> 主角：**Clawd 方盒小人**，原色陶土 `#D97757`（不改色）；第二角色粉色 `#E58384`（同骨架 `tint:'rosy'`），只作为**玻璃上的倒影**存在，全片不上地板、不留影子。
> 借法：painted-animation **只借 Clawd 的表情与动作库**（31 情绪 / 11 舞步 / 5 视图 / emote / 五官参数），**不借水彩笔触与 line boil**；人物按 cel-anime-80s 的色指定重上色，线稿用彩线不用纯黑。
> 画幅 **16:9 / 1920×1080**｜**24 fps / 736 帧**｜时长 **30.642 s**｜**65 拍，65 个事件，零空拍**
> 本轮交付：**只有分镜提示词**，未渲染、未改任何工程文件。v4（game-show）留档不执行。

## 0. 为什么是「80 年代赛璐璐」

| 歌里的问题 | 这个画风给的解法 |
|---|---|
| **幻听**——她不在，但声音在 | 风格原生的一层：**玻璃**。80s OVA 的窗玻璃永远是"能照出人、又照不透"的第二层空间。倒影是**光**（emissive 层），不是人——所以它能在窗外、在水洼里、在表盘反光里同时出现，且从不落地、从不投影子 |
| 「如今一个人听歌 总是会觉得失落」 | 房间里**两把椅子**。第二把空着，椅面上一副耳机摆得整整齐齐。全片的"一个人"不靠台词说，靠这把椅子 |
| 「你有多爱我」 | **VU 表**：80 年代录音机的电平表是"感情唯一可以被量出来的地方"。指针冲到红区顶端、撞限位、掉回零——一个数字化的答案，而且它自己会回到零 |
| 「爱已不在这里 我却还没走脱」 | 80s 特有的**"人比镜头慢半档"**：角色 on twos（12 fps），镜头 on ones（24 fps）。他每动一下都比画面慢一点——身体已经停不下来，画面也没等他 |
| 「列表里的歌 随过往流动」 | **磁带**。列表就是 J-card 上手写的 01–07；拉出来的带子就是"流动"。这条带子最后横过整座城市，从顶视看是一条河 |
| **全程高能 / 每鼓点有变化**（本次硬要求） | 80s OVA 的高能不靠"闪"，靠**四件事同时不停**：光带横扫（不改变形就能给变化）、百叶窗影（每拍一道）、冲击帧（全片只用 5 次，用一次顶一次）、硬切（16 个小节头全切）。角色侧每拍给表情或姿态 |

**三个大时刻**：
1. **k0（0.04）CRT 开机**：亮点 → 亮线 → 画面。扫描线扫过之处房间才存在，扫到他身上他才"出现"。开场 3 秒 3 次尺度变化（全屏亮线 → 房间 wide → 椅子 medium）。
2. **15.68（人声进副歌，不在拍上）玻璃整块向外碎**，360 片；他跨出窗，站在一层不存在的空气地板上；城市全亮。
3. **k62–k64（29.17–30.64）CRT 关机**：画面收成线、再收成点；点在最后一拍亮一记粉色；噪声条滚过；硬切黑。**与开机的 k0 成对**。

## 1. 一句话

他一个人在一间 80 年代的房间里听一首两个人的歌。玻璃上慢慢长出第二个人，跟他一起唱、一起跑、一起按手。副歌最响的时候玻璃碎了，城市全亮；可他回头，那个位置永远慢半拍。最后他把磁带收好、按停、关掉电视——黑掉前的那一帧，那个点还亮了一记粉色。

**视觉总原则**：一切"动"都由 80s OVA 的四种机制给出——**光带、百叶窗影、冲击帧、硬切**；角色永远 on twos 阶梯运动，镜头永远 on ones 平滑。**没有人比镜头快**，这就是"走不脱"。

## 3. 音乐事实（2026-11-07 实测，唯一卡点依据）

**来源**：`analyze_drums.py` → `鼓点实测.json`；字幕时间来自 `11月7日-字幕音频对照.json`。

| 项 | 实测值 |
|---|---|
| 时长 | **30.642 s** |
| 速度 | 自相关 **127.60 BPM**；拍网格取 **127.7**（`t = 0.04 + 0.4699·k`），因为这样 k32 = 15.077 更贴近实测强击 15.075 |
| 拍网格 | **k = 0…64，共 65 拍**；k64 = 30.11 s，仍在曲内 |
| 小节 | 4 拍 = 1.8796 s；**16 个整小节 + k64 第 17 小节头**；小节头 k0/4/8/…/60 |
| 响度 | **全程平坦**：每拍 RMS 0.47–0.58，**没有抽鼓、没有真空**；只有 k61 起变稀（0.17 → 0.14） |
| 弱拍 | **k1 = 0.22 / k35 = 0.36 / k61 = 0.17 / k62 = 0.14 / k63 = 0.54 / k64 = 0.44** |
| 最强拍 | k6 / k12 / k16 / k24 / k28 / k32 / k36 = 1.00；k38 / k42 / k48 = 0.99 |
| 句首（不得改） | **0.70 / 5.36 / 8.92 / 11.12 / 15.68 / 20.34 / 23.92** |
| 副歌进入 | **15.68**，落在 k33(15.54) 与 k34(16.02) **之间，不在拍上** → 单独大时刻，不塞进拍表 |

**⚠ 三条必须在开工前说清的事**：

1. **逐字强制对齐没有做**。`.ass` / `.srt` / `.lrc` 只有整句时间，没有 `\k` 逐字标签，对照 JSON 也注明"句内逗号处没有真实停顿"。因此本版**只做整句上屏，不做逐字卡点**；§6 的反拍层是**鼓点层**，与歌词逐字无关。这条不许开工后被悄悄改掉。
2. **`鼓点实测.json` 的 `segment` 字段有错**：k10 / k11 / k18 / k22 / k23 标成"间奏"，但 L1 实际唱到 4.60、L2 唱到 8.35。**以字幕时间为准，`segment` 字段只当参考。**
3. **k31 之后的"间奏"标注不可信**：k34 起人声已进副歌，但字段仍写"间奏"。本版按字幕段落走。

**卡点四层**：拍级 65 次（§9 主表）／反拍级 65 次（§6.2）／小节级 16 次（硬切）／句级 7 次（字幕 + 叙事转折）+ 1 次非拍点大时刻（15.68）。

## 4. 世界设定

### 4.1 场景（全片只有三个空间，互相套着）

| 空间 | 何时 | 是什么 |
|---|---|---|
| **房间** | k0–k19、k44–k64 | 80 年代单人房：一张桌子、一台双卡录音机、一把椅子在桌边、**另一把椅子在窗边空着**、一扇竖条百叶窗。墙是深暖棕，天花板有一盏钨丝灯。全片不变形、不搬家具 |
| **窗（玻璃）** | 贯穿全片 | 画面的第二层。玻璃既照人也照夜。倒影只存在于这一层；光只从这一层进来；碎、雾、手印、雨都发生在这一层 |
| **城市** | k20–k43 | 窗外的霓虹夜城：4 层视差的楼、湿街、水洼、玻璃幕墙。只在"穿过玻璃"之后才存在 |

### 4.2 四套色指定（`色指定`，按光照切换，不是滤镜）

| 套 | 何时 | 环境 | 主角 mid / 亮 / 暗 / 线 / rim |
|---|---|---|---|
| **A 室内钨丝** | 0.00–9.44 | 墙 `#3A2A24`、灯 `#F3B24A`、窗外 `#1B1E3C` | `#D97757` / `#E9966F` / `#A6502F` / `#57281B` / `#FFD79A` |
| **B 霓虹夜窗** | 9.44–13.20 | indigo `#1B1E3C`、magenta `#FF4E8A`、cyan `#37D6E0`、窗金 `#F3B24A` | `#D97757` / `#EC8E68` / `#8E4A44` / `#5A2A28` / `#FF7BB0` |
| **C 雨玻璃 / 副歌** | 13.20–20.71 | 冷青为主，湿反射；全片最亮的一套 | `#C4694F` / `#DE8365` / `#7E3F3C` / `#4E2725` / `#6FE3FF` |
| **D 尾奏冷蓝** | 20.71–30.64 | `#1A2330`，唯一的暖色是 **磁带带金 `#E8B94A`** 与 CRT 绿 `#8FE3B0` | `#A85B49` / `#C06E58` / `#5E3434` / `#3A1F1E` / `#8FE3B0` |

**换套只在小节头，用 1–3 帧白闪接，绝不逐帧插值。**

### 4.3 四条硬规矩

1. **倒影不上地板**：粉 Clawd 永远在玻璃、水面、表盘、幕墙里，**从不出现影子，从不挡住实景**；它的边缘永远有 1–2px 的横向色散 + 扫描线切割。
2. **角色 silhouette 必须 stamp 进 emissive 板**：否则霓虹会从人物身体里透出来（STYLE §2 明确列为 pitfall）。
3. **角色 on twos，镜头 on ones**：任何一帧角色和镜头同速 = 失去 80s 质感。角色 12 fps 的阶梯**不许平滑**。
4. **没有 dissolve、没有数字 wipe、没有柔和渐变转场**：只有硬切、白闪、冲击帧、tracking noise。

## 5. 角色设定（Clawd）

### 5.1 借什么、不借什么

| | 借 | 不借 |
|---|---|---|
| painted-animation | **方盒身 / 四短腿 / 两竖眼**造型；31 情绪；11 种 `move()`；5 视图 `turn()`；`emotions()` 的 anticipation-squint-take-overshoot；emote 标记；`eyes/mouth/lookX/lookY/squint/blush/gloom/lid/tint` 参数；帽子 `headphones` | 水彩笔触、`paint()/inkLine()`、line boil、`glow()` 加色光、p5.brush、它的任何场景与故事 |
| cel-anime-80s | **色指定**（mid/lit/shadow/line/rim 五值一套）、硬边阴影+硬边高光、**彩线不用纯黑**、on twos 阶梯、emissive 板 + bloom、CRT 磁带后处理、冲击帧、光带横扫、速度线 | 它的人物头身画法（Clawd 是方块，不套 80s 人头）；它的 demo 城市与角色 |

**形不变**：Clawd 永远是 10u × 8u 的方盒，四短腿，两竖眼，戴 `headphones`（全片不摘，是"听歌"的实体）。粉色倒影是同一骨架 `tint:'rosy'`、同一副耳机，只在**透明度、色散、扫描线**上区分。**全片不超过两个人物，不新增第三色。**

### 5.2 赛璐璐上色规则（Clawd 专用）

- **描边**：3px 彩线（`#57281B` 等），特写时缩到 1.5–2px；**绝不用纯黑**。
- **阴影**：一道硬边月牙，方向由当套光源定（A 套左上来光、B/C 套背后逆光、D 套 CRT 屏幕光从左下）。
- **高光**：一道硬边月牙 + 一条 2–4px 的饱和霓虹 rim（只在 B/C 套）。
- **不做 cel 内渐变**（唯一例外：★15.68 那一帧允许一张 "harmony" 手绘静帧）。
- **方盒的四个面用三条线断开**，避免读成一块色块；眼睛是两条竖缝，不画瞳孔反光（会读成日式萌眼）。

### 5.4 动作 / 视图 / emote 分配

- **11 舞步**：`bounce`（默认 idle，全片不停，每拍 hop 6–24px）／`stomp`（k29–31 走向窗，踩在拍上）／`hop`（k34 站上空气地板、k55 跳出画）／`run`（k36–43 城市、k54 追带子，8 张循环一步一拍）／`spin`（★15.68 一次，5 张视图 + smear）／`wave`（k17–19 对唱与按玻璃）／`shimmy`（k31 半拍）／`sway`（k21–23 夜色、k57 带子河）／`roof`（k34 副歌举手、k57）／`walk`（k53 拿磁带）／`idle`（只在半拍内的极短 hold 用，≤1 拍）。
- **5 视图**：`front`（默认）／`q`（k7 看空椅、k45 看玻璃）／`side`（k37 跑、k54 追）／`qback`（k44 背影）／`back`（k44 一瞬）。转身一律 `turn(t,t0,t1,a0,a1)` 走 0.12–0.25 s 关键帧 + smear，**不许一帧翻面**。
- **emote**：`music`（对唱）／`!` `?`（发现倒影）／`hearts`（k38 手对手）／`sweat`（S07、S10）／`spark`（k57）／`dots`（k51）。
- **眨眼落在非拍点**（避开冲击帧抢读），只有 k1 / k35 / k61 三处例外——那三拍**眨眼本身就是事件**。

## 6. 高能机制（本次硬要求的量化落点）

### 6.1 每拍至少命中一类，65/65

每一拍必须**至少有一项**可见变化，类型只有 6 种：**效**（光带/雨/雾/速度线/碎屑）、**镜**（运镜）、**表**（表情）、**作**（姿态动作）、**切**（硬切/转场/冲击帧）、**画**（画面上多一件东西）。§9 逐拍表每拍都标了类型；"成片里看不出变化的一拍 = 没做对的一拍"。

| 段 | 每拍件数下限 | 活元素下限 |
|---|---|---|
| S01–S05（k0–19，主歌） | **1–2 件** | ≥3（他 + 光带或百叶窗影 + VU 针/雨） |
| S06–S07（k20–27，夜色/打分） | **2 件** | ≥4（城市/霓虹/雨/表盘） |
| S08 + ★（k28–35，爬升与炸开） | **2–3 件** | ≥5 |
| S09–S10（k36–43，副歌） | **2–3 件** | ≥4 |
| S11–S12（k44–51，雨） | **2 件** | ≥3 |
| S13–S15（k52–64，磁带与关机） | **1–2 件** | ≥2（最后一拍只允许两件，见 §6.3） |

**音乐响度是平的** → 起伏**不靠音量、不靠"停住"**，靠**事件密度 + 冲击帧的位置**：1–2 件 → 2 件 → 3 件 → 3 件 → 2 件 → 2 件。arc 的骨头是三记冲击帧：k6（扣耳机）、★15.68（碎玻璃）、k64（灭）。

### 6.2 反拍层（每拍 +0.235 s）

实测反拍能量 0.51–1.00（k24、k35 达 1.00），所以每拍设一次**微事件**，只做一样、不抢正拍：光带移一档 / 百叶窗影移一条 / 雨点跳一格 / VU 针跳一下 / 磁带走带轮转一格 / 眨眼一次 / 碎屑飘一格。

### 6.3 弱拍与留白：留白 ≠ 静止

| 拍 | 实测 | 处理 |
|---|---|---|
| **k1 (0.51)** | 0.22、RMS 0.196 | 开场留白：**只动两样**——他眨一次眼 + 手指按下 play（键下沉 2px，磁带开始转）。光带停、雨停。反拍 0.90 有能量 → 半拍处 VU 针跳一格 |
| **k35 (16.48)** | 正拍 0.36 / **反拍 1.00** | **切分拍**：正拍只眨眼 + 一片玻璃碎片停在他鼻尖前；把所有能量让给 +0.235 s 的**全部碎片同时爆开** + 3% punch |
| **k61 (28.70)** | 0.17 / 反拍 0.16 | 结尾留白，与 k1 **成对**：只眨眼 + 按 stop（键回弹 2px） |
| **k62 (29.17)** | 0.14（全片最弱） | CRT 关机：画面从四周收成一条线，再收成一个点。**不 punch** |
| **k63 (29.64)** | 0.54 | 那个点在最后一拍**亮一记粉色**；他抬头。全片最后一次"她还在这里"的证据 |

### 6.4 运镜（只做 80s 允许的六式 + 三个本片专用）

## 10. 字幕 / telop 规格

- **字体**：思源黑体 CN Medium（与 `11月7日.ass` 一致），**52–56 px**，字距 +1。
- **样式**：奶黄 `#FFF3D6` 字面 + 深棕 `#2A1C18` 3 px 描边 + 一层很淡的软影（80s 电视字幕永远是"贴"在画面上的，不是 UI 层）。
- **位置**：底边上方 **96 px** 居中，**永远不压他的脸、不压 VU 表指针**。
- **烧进 CRT pass 内部**：字幕跟着扫描线、色度渗色、荧光晕一起被处理——这是全片"字幕也是磁带的一部分"的关键，不许最后叠加。
- **上屏方式**：不带 fade，**硬上硬下**（80s 字幕是切换，不是淡入）。
- **停留**：`≥ max(1.8 s, 语音 + 0.6 s)`。**L3「夜色多温柔」只有 1.36 s** → 允许**向前借 0.12 s**（8.80 上屏，停到 10.92，共 2.12 s），**不许向后压 L4**。其余六句按原时间即可。
- **唯一例外**：J-card 上手写的 **01–07** 是道具字（8–10 px，允许读不清），不算字幕，也不算"文字滥用"。全片**不出现片名、不出现歌词大字**。
