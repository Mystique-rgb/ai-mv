# 《幻听》MV 分镜提示词 v4 ｜ 一个人的对唱（综艺节奏扁平）

> 画风：**综艺节奏扁平 Game Show Flat**（lemo-opuscar `styles/game-show`，STYLE.md 为硬约束）
> 结构：一台**双人节奏游戏**的正面舞台。左边是他的位，右边是「2P 应答位」——从头到尾没有人。整首歌他每一拍都在接音符，而 2P 的分数栏一直在跳。
> 主角：**Clawd 方盒小人**，原色陶土 `#D97757`（不改色）；第二角色粉色 `#E58384`（同一骨架 `tint:'rosy'`），只作为**幻听残影**出现，不新增第三个人物身份。
> 借法：painted-animation **只借 Clawd 的表情与动作库**（31 情绪 / 11 舞步 / 5 视图 / emote / 五官参数），**不借水彩笔触**；人物按 game-show 的 8px 墨线平涂重描。
> 画幅 **16:9 / 1920×1080**｜时长 **30.642 s**｜**65 拍，65 个事件，零空拍**
> 本轮交付：**只有分镜提示词**，未渲染、未改动 v1/v2/v3 任何工程文件。旧版留档不执行。

## 0. 为什么是「综艺节奏扁平」

| 歌里的问题 | 这个画风给的解法 |
|---|---|
| **幻听**——她不在，但声音在 | 风格原生的 **call-and-response（一问一答）**：他喊一拍，右半屏在反拍弹出一个粉色残影应答。残影是**判定特效的一部分**，不是真人；归到 slot 里就没了 |
| 「如今一个人听歌 总是会觉得失落」 | 舞台是**双人**的：两块地板、两条判定线、两个 COMBO 栏。2P 位空着，但 **2P COMBO 数字还在涨**——"一个人"不是靠他孤零零站着说，是靠 UI 说 |
| 「你有多爱我」 | 风格原生的 **judgement word / 打分牌**：粉色残影举牌打 10/10，牌翻过来**背面是空白** |
| 「爱已不在这里 我却还没走脱」 | 判定线**继续滚**，他 `move('bounce')` 不减速，判定词变成 `MISS / NO ANSWER`。"走不脱"= 停不下来的节奏游戏 |
| 「列表里的歌 随过往流动」 | 风格原生的 **Remix board**：所有 round 卡缩回底部槽位，再一起弹起排成一条横向传送带流过画面 |
| **全程高能 / 每鼓点有变化**（本次硬要求） | STYLE 第一条就是 "**Everything is on the grid**"：每个 pop / drop / stamp / 打字 / 镜头 punch 都落在 (bar, beat)。**空拍在这个画风里属于画错了**，不是风格选择 |

**和 v3（纸片立体书）的关系**：v3 走"纸的物理"，结尾是合书、静止、留白。本版反过来——**全片不许有静止收尾**，最后一拍是最大字号判定词 + 全屏冲击帧 + 硬切黑。同一个故事，换成"他停不下来"的讲法。v3 的 65 拍表、纸城、褪色、合书全部作废，不复用。

**三个大时刻**：
1. **k0（0.04）** 舞台撕开 + 他从天上砸下来 + 判定线落地，开场 3 秒连做 3 次尺度变化。
2. **15.68（人声进副歌，不在拍上）** 画面从中间裂成两半 → 双判定线 → 音符 3/拍 → 四个粉色残影同时 drop-in。
3. **k64（30.11，最后一帧）** `AGAIN?` 盖满全屏 + 5% punch + 1 帧反相冲击帧 + 硬切黑，他定格在 hop 最高点。

## 1. 一句话

他把一首两个人的歌，玩成了一局一个人的双人节奏游戏。右半屏幕每隔一拍就弹出一个粉色小人跟他一唱一和，分数栏两个人的数字一起涨；到副歌他才发现，右半屏从头到尾是空的，粉色小人是他自己按出来的残影。可判定线还在滚、音符还在落，他一拍也没停——最后结算画面上只剩一个 `AGAIN?`。

**视觉总原则：一切"动"都由节奏游戏的规则给出**——落音符、hop、squash、判定词 pop、镜头 punch、硬切换 set、卡片缩进 slot。不出现游戏做不到的动作；不出现没有拍点的运动。

## 3. 音乐事实（2026-11-07 独立实测，唯一卡点依据）

**方法**：`ffmpeg` 解 22050 Hz 单声道 → 35–150 Hz 带通包络 + 谱通量 → 自相关定速 → 逐拍 ±0.12 s 窗口取低频峰值、+半拍 ±0.09 s 窗口取反拍峰值。脚本 `analyze_drums.py`，读数 `鼓点实测.json`（本轮新建，可复核）。

| 项 | 实测值 |
|---|---|
| 时长 | **30.642 s** |
| 速度 | 自相关 **127.60 BPM**（周期 0.4702 s） |
| 拍网格 | **`t = 0.04 + 0.4699·k`，k = 0…64**（k64 = 30.11 s，仍在曲内）。取 127.7 而非自相关 127.60，是因为前者让 k32 = 15.077 更贴近实测强击 15.075；两者 65 拍累计仅差 0.02 s |
| 小节 | 4 拍 = 1.8796 s，共 **16 个完整小节 + k64 第 17 小节头**；小节头 k0/4/8/…/60 |
| 击点 | 全局峰值匹配 65 拍中命中 60，落空 `[3,4,7,15,19]`（方法差异，见下）；窗口能量逐拍均有读数 |
| 响度 | **全程平坦**：每拍 RMS 0.47–0.58，**没有抽鼓段、没有真空白**；仅 k61 起变稀（0.23 → 0.18） |
| 弱拍（窗口能量） | **k1 = 0.22 / k35 = 0.36 / k61 = 0.17 / k62 = 0.14 / k63 = 0.54 / k64 = 0.44** |
| 反拍 | 每拍 +0.235 s 的低频能量普遍 **0.51–1.00**（k24、k35 达 1.00），歌里确有稳定八分音符层 → 半拍事件有依据 |
| 最强拍（窗口低频前 10） | k6 / k12 / k16 / k24 / k28 / k32 / k36 = 1.00，k38 / k42 / k48 = 0.99 → 全部落在小节头或副歌。k6/k16/k24/k36/k38 配 punch ≥4% + burst；k12/k28/k32/k42/k48 配硬切、尺度跳变、白闪或 punch 3%（不与大 punch 叠加，避免同帧超限） |
| 句首（不得改，来自 `11月7日-字幕音频对照.json`） | **0.70 / 5.36 / 8.92 / 11.12 / 15.68 / 20.34 / 23.92** |
| 副歌进入 | **15.68**，落在 k33(15.54) 与 k34(16.02) **之间，不在拍上** → 单独大时刻，不塞进拍表 |

**⚠ 与 v3 实测的差异，按本表执行：**
1. v3 记 127.7 BPM / 拍长 0.4704 / k64 = 30.15。本轮 127.60 / 0.4699 / 30.11。**差 0.04 s 以内，不影响事件归属**，但所有时间以本表为准。
2. v3 记「k1、k61 无底鼓」。本轮**窗口能量确认** k1 = 0.22、k61 = 0.17 明显弱，**两套实测在这两拍上吻合** → 仍设为**成对留白拍**。但按本次硬要求，留白 ≠ 静止，见 §6.3。
3. 全局峰值匹配的落空拍是 `[3,4,7,15,19]`，与 v3 不同，原因是本轮用了 0.20 s 最小峰间距 + 全局 prominence 筛选，**这些拍窗口内其实有能量**（0.77–0.93）。**不得据此把它们做成空拍。**
4. 新增弱拍 **k35**：正拍低频 0.36、反拍 1.00 → 这是**切分拍**，本片唯一"正拍留白、反拍最满"的一拍（§9 k35）。
5. **逐字强制对齐没有做**：`.ass` / `.srt` / `.lrc` 只有整句时间，没有 `\k` 逐字标签，对照 JSON 也注明"句内逗号处没有真实停顿，未强行切分"。因此本版**只做整句上屏，不做逐字卡点**；§6 的半拍层是**鼓点层**，与歌词逐字无关。这条不许在开工时被悄悄改掉。

**卡点四层**：拍级 65 次（§9 主表）／反拍级 65 次（§6.2 微事件）／小节级 16 次（硬切换 set）／句级 7 次（字幕上屏 + 叙事转折）+ 1 次非拍点大时刻（15.68）。

## 4. 世界设定

### 4.1 舞台（全片不变）

正面、左右对称的 proscenium。一条 **8px ink 判定线**横贯画面下三分之一，线下方是深色 floor band（带上沿墨线）。左位「1P」站主角，右位「2P」从头到尾是一圈 **cream 虚线框**（歪 2°），框上贴一张卷角的名牌。左上角角标 banner，正中上方判定词位，右上计分板（1P COMBO / **2P COMBO / 2P 总分 `--`**）。底部一排 slot，收着打完的 round 卡。

背景 = 一个饱和色 + 同色系斜条 / 圆点 / 旭日，斜条**按拍跳格**（不是匀速滚）。每个 round 换一套色，**相邻不重色**；换色只在小节头硬切 + 2 帧白闪。

### 4.2 九个 round 与色板（ink `#1D1A17`，不用纯黑；cream `#FFF3DC`）

| Round | 拍 | set 色 / 图案 | 对应歌词 | 这一 round 的"可重复动词" |
|---|---|---|---|---|
| R0 | k0–3 | cream `#FFF3DC` / 黄斜条 | 无词 count-in | 弹开舞台 / 落判定线 |
| R1 | k4–11 | blue `#2E7DD1` / sky 圆点 | L1 一个人听歌 | 接住落下的音符 |
| R2 | k12–19 | teal `#149E92` / mint 斜条 | L2 幻听你在耳边 | 一喊一答（半拍错位） |
| R3 | k20–27 | navy `#20366B` / gold 旭日 | L3 夜色 / L4 你有多爱我 | 举牌打分 |
| R4 | k28–35 | lime `#8CCB3F` / ink 圆点 | 间奏起拍 → 副歌 | 密度加倍（2→3 件/拍） |
| R5 | k36–43 | violet `#6C4BC4` / gold 旭日 | L5 难过（副歌） | 四个残影齐跳、错版 |
| R6 | k44–51 | deep plum `#3B2A62` / cream 星 | L6 爱已不在这里 | 残影被逐个擦掉，他不停 |
| R7 | k52–59 | sky `#4CB7E8` / 白圆点 | L7 列表里的歌 | round 卡流成河 |
| R8 | k60–64 | yellow `#FFD24A` / ink 斜条 | 尾奏 AGAIN? | 重新 count-in、循环 |

> 角色色与 set 色**永不同色相**（STYLE §3）：陶土橙与粉都避开了橙/粉系背景；副歌 violet / plum 是冷底，主角和残影才跳得出来。

### 4.3 三条硬规矩

1. **一切必须在拍上**：任何 pop / drop / stamp / 打字 / 硬切 / punch 落在 `0.04 + 0.4699·k` 或其半拍 `+0.235`。**没有"自由流动"的运动**。
2. **2P 位永远没有真人**：粉色残影只以「判定特效」「卡反光」「网点半帧」的形式出现，从不站在地板上留下影子。全场唯一一次"像真人"是 k38 的轮廓，且立刻化成网点散掉。
3. **他从头到尾没停过**：包括两处留白拍、包括哭的时候、包括最后一帧。停的只有"脚"（k51），画面不许停。

- **5 视图**：`front`（默认）／`q`（侧头看 2P）／`side`（横向追残影）／`qback`／`back`（k47 一瞬）。转身一律 `turn(t,t0,t1,a0,a1)` 走 0.12–0.25 s 关键帧 + smear，**不许一帧翻面**。

- **眨眼落在非拍点**（避免与 punch 抢），只有 k1 / k35 / k61 三处例外——那三拍**眨眼本身就是事件**。

## 6. 高能机制（本次硬要求的量化落点）

### 6.1 每拍至少命中一类，65/65

每一拍必须**至少有一项**可见变化，类型只有 6 种：**动效 / 运镜 / 表情 / 动作 / 判定词 / 转场**。§9 逐拍表每拍都标注了类型；"成片里看不出变化的一拍 = 没做对的一拍"。

| 段 | 每拍件数下限 | 活元素下限 |
|---|---|---|
| R0–R3（主歌 k0–27） | **1–2 件** | ≥2（音符 + 判定词或条纹 / 计分板） |
| R4（k28–33 起拍） | **2 件** | ≥3 |
| R5–R6（副歌 k34–51） | **2–3 件** | ≥3 |
| R7–R8（k52–64） | **2 件** | ≥2 |

**音乐响度是平的** → 起伏**不靠音量、不靠"停住"**，靠**事件密度**做 arc：1 件 → 2 件 → 3 件 → 3 件 → 2 件 → 3 件（尾奏最后一拍反而最大）。这是本版与 v3 最根本的差别。

### 6.2 反拍层（每拍 +0.235 s）

实测反拍能量 0.51–1.00，因此每拍设一次**微事件**（不改变主画面）：条纹跳一格 / 计分板 +1 / 2P slot 闪一下 / 残影网点重排 / 打字机一个字 / 一次 blink。**只做一样**，不与正拍的主动作抢读。

### 6.3 留白拍与弱拍：留白 ≠ 静止

| 拍 | 实测 | 处理 |
|---|---|---|
| **k1 (0.51)** | 低频 0.22、RMS 0.196 | 开场留白：**只动两样**——他眨一次眼 + count-in「3」翻成「2」；条纹停、音符不落。反拍 0.90 有能量 → 半拍处 2P 空位 cream 虚线亮一下 |
| **k35 (16.48)** | 正拍 0.36 / **反拍 1.00** | **切分拍**：正拍只眨眼 + 判定词翻成 `PERFECT?`；把所有能量让给 +0.235 s 的四个残影齐 squash + 3% punch |

## 10. 字幕 / telop 规格

- **telop 就是字幕**，不是外加的细字幕条：`paint-order:stroke`，白/黄填充 + **ink 描边 ≈ 字号 14%**，无柔阴影。CJK 用 Noto Sans SC 900，数字/拉丁用 Fredoka 700（或同权重圆体）。
- 主字幕为**底部 telop plate**（角标 banner 承载关键词，≤20 字/行）；字号 **≥108px**。角标在左上、判定词正中上，**不许压住主角的脸和 hop 落点**。
- **7 句上屏时间严格等于** `0.70 / 5.36 / 8.92 / 11.12 / 15.68 / 20.34 / 23.92`，结束 `4.60 / 8.35 / 10.28 / 12.92 / 19.58 / 23.45 / 26.85`。**不早于开唱 0.35 s、不晚于 0.15 s**；逐字 pop 只是"telop 内部的打字机效果"，**不是逐字卡歌词**（§3 已注明无逐字对齐数据）。
- 句间空档保持干净；prints don't fade——**只硬切，不淡入淡出**。判定词可短（一眼读完），字幕至少留到句尾。
- 卡片编号只用 **01–07**，**不写真实歌名、不出现任何品牌 / 产品名 / logo**。
