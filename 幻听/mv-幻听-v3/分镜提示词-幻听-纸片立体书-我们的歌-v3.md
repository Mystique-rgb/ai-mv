# 《幻听》MV 分镜提示词 v3 ｜ 我们的歌（纸片立体书）

> 画风：**纸片立体书 paper-popup**（lemo-opuscar `styles/paper-popup`）
> 结构：**一本摊在真实桌面上的立体书**。书名叫《我们的歌》，每一页是一段"夜里一个人听歌"的记忆；主角住在书里，是书里的一张纸人
> 主角：**clawd 方盒小人**，陶土橙 `#D97757`；第二个角色粉色 `#E58384`（她是**被撕掉的那一页**上的人，只能从折页里出现）；群演：3 个灰纸小人，只在副歌纸城出现
> 画幅：**16:9 / 1920×1080**｜时长 30.64s｜**65 个拍位，每一拍都有机关或动作**
> v1（积木歌单）、v2（活体录屏）按用户指令停用，留档在原目录，不再执行

## 0. 为什么是纸片立体书

三个理由，每个都对应这首歌的一个真问题：

| 歌里的问题 | 纸片立体书给的解法 |
|---|---|
| 「幻听」——她不在，但声音在 | 她是**一个折页**：人不在，机关在。折页一弹，她就"在"；一合，她就没了。她能不能出现，由纸的物理决定，不由剧情决定 |
| 「一个人听歌 总是会觉得失落」 | 纸片人**没有厚度**：他是剪出来的、平的。他伸手去够空杯子，手指从剪口穿过去——"够不着"是画法本身 |
| 「列表里的歌 随过往流动」 | 立体书页边上就有**抽拉条**：一抽，歌名就变成纸带被拉出来。歌词说的动作，正好是这个画风的原生动作 |

**和 v1/v2 的关系**：v1 是积木（世界是搭出来的），v2 是界面（世界是点出来的）。这一版的世界是**折出来的**——所有东西都从一条折线立起来，也都能折回去。所以这一版的"高能"不靠镜头晃，靠**机关连锁**：一拍弹一个，一拍塌一个。

**三个升级点（每条都有落点）：**

1. **开头 0.70 秒 4 连事件**：纸尘 → 弹出 V 折（震屏 2px）→ 贴书脊前推、纸片擦镜两次 → 他从折页里被弹出来砸在页上。
2. **副歌不只炸，还褪色**：纸城弹到最高时，整页**褪成铅笔稿**（画风自带的"未完成页=石墨"规则），只剩他是彩色的。"难过"不写在脸上，写在纸的材质上。
3. **结尾是合书**：书自己合上，他被夹在纸缝里，缝越来越窄，他抬手贴在纸上。最后 4.6 秒只有纸在动，人一动不动——最狠的收。

## 1. 一句话

他住在《我们的歌》这本立体书里。写她的那一页被撕掉了，只剩参差的纸根；她一出现就是从折页里弹出的半张脸，一合页就没了。整首歌里，他把书页一层层弹成一座纸城，跑到书的边缘想跨出去，被折回来的纸页夹住；最后四条歌名被抽成纸带流走，书自己合上。

**视觉总原则：一切"动"都由纸的物理给出**——弹起、折下、抽出、翻过、贴住、撕开、夹住。不出现纸做不到的动作。

**⚠ 两处纠正（旧文档写过、这次实测不成立，一律按本表）：**
1. 旧 v2 文档说「17.43–19.20 抽鼓」。**实测不成立**：17.89 与 18.36 两击是全曲最响的一批（0.94 / 0.84）。这一段不能做成"停住"，要做成"最满"。

## 4. 世界设定

### 4.1 两层

| 层 | 是什么 | 规矩 |
|---|---|---|
| **真实层** | 一张胡桃木桌、一盏绿罩黄铜台灯、一只冷掉的茶杯（有茶渍圈）、一根她的发圈、一副真实的有线耳机（线搭在桌面上）、空气里的尘 | 永远不虚焦到看不清；只做前景/背景；**全片没有出现过人手**；木纹、台灯、发圈、耳机线是"真的"——现实必须比纸更沉 |
| **书层** | 一本打开的立体书《我们的歌》，硬壳布面、书脊烫金书名、页块有厚度、书页会卷 | 所有纸片从**折线**立起、按**由远及近**的顺序弹起；合上时反向折下 |

### 4.2 书里的七页（每一页是一段记忆）

| 页 | 页名 | 主色系 | 对应歌词 | 页上有什么 |
|---|---|---|---|---|
| P1 | 小屋页 | 暖米 + 陶土橙 | L1 | 纸墙、纸窗、纸卡座、两把椅子（第二把是**贴上去又撕下的残迹**）、两只杯子（一只被剪掉缺口）、墙上手写四行歌名 |
| P2 | 耳朵页 | 米白 + 粉 | L2 | 一块巨大的纸耳罩、从折页弹出的她、纸声波锯齿条 |
| P3 | 夜页 | 靛蓝 + 姜黄 | L3 | 从下翻上来的深蓝纸夜空、挂在绳上的纸月亮、纸雨、纸屋顶 |
| P4 | 刻度页 | 朱红 + 米白 | L4 | 一块 0–10 的纸板刻度牌、被压弯的折线 |
| P5 | 纸城页 | 五色全开（红/姜黄/靛/粉/松绿） | L5 | 12 栋纸楼、招牌、街灯、一辆纸车、3 个灰纸群演 |
| P6 | 撕页 | 铅笔稿（石墨 + 米白） | L6 | 参差的撕边、装订缝（gutter）、页下的真实木纹；这一页**没有颜色** |
| P7 | 抽拉页 | 彩带（朱红/姜黄/靛/粉） | L7 | 四条抽拉条、页边槽口、歌名手写 |

### 4.3 三条硬规矩

1. **一切由折线决定**：任何立体结构必须能指出它的折线在哪、折角多少。画面上不许出现"没有折线却立着"的东西。
2. **书不会自己变**：除三个"自己动"的例外——P2 的折页（她）、P7 的抽拉条（歌）、结尾的合书（风）。其余机关都由他触发（他踩、他拉、他推、他压）。**因果必须看得见。**
3. **真实层只被"风"和"光"影响**：台灯会晃、发圈会滑、纸尘会飞，但桌子不动、书不飘。

## 5. 角色设定

### 5.1 他（陶土橙 clawd）

| 项 | 规格 |
|---|---|
| 形 | 方盒身（宽:高 = 1:1.15），四条短腿，两只眼睛，无嘴；边缘略不齐（低次谐波噪声，不用完美几何） |
| 纸 | **剪纸**：平涂 + 一根深棕墨线（`#3B2A20`，绝不用纯黑）+ 一道硬月牙阴影 + 一圈 4–6px **奶白边**（剪出来的白边）+ 灰卡纸侧厚（向下偏 2px） |
| 色指定 | 亮 `#E79A72`／平 `#D97757`／影 `#A2502F`／线 `#5B2718`；台灯下微微加暖；铅笔稿段落里**只有他保留彩色** |
| 尺寸 | 页面上高 **42 mm**（页宽 420 mm）——约一页的 1/10，够大，能看清眼 |
| 关节 | 腿 2 段、手臂 2 段；转身 = `scale.x` 翻面（**不许** `rotation.y`，会看到白背） |
| 眼 8 位 | 平/左/右/上/下/瞪/眯/闭；眨眼不规则（每 2–4 秒一次，落在非拍点上） |
| 动作库 12 | 站、走、跑、跳（抛物+两头压扁）、落下砸扁、爬、拉、推、踩、贴（掌心贴纸）、够（伸手抓到空）、回头 |
| 二次动作 | 耳机线（真线）随手甩、白边随动作轻抖、落地扬纸尘 |

**表演规则（"活灵活现"的具体做法）**
1. 每个动作三张：**预备张 → 极端张（1 帧拉长/压扁，可以过头）→ 落定张**。极端张必须有。
2. 走和跑的步频跟距离走，不跟时间走（脚不许滑）。
3. 情绪只给三样：眼睛、身体倾角、手。**不给嘴。**
4. 他每次伸手都是"够不到"——这是全片的表演母题（空杯、空椅、纸缝外的光、桌沿下的黑）。

### 5.2 她（粉纸 `#E58384`）

- **她不是一个人，是一张折页**：只有 P2 弹出时完整（半身 + 一只手，侧脸）；其余时候只是纸边一线、一道粉色透光、一个投影。
- 她的出现永远由**机关**决定：折页弹起（k13）、被压弯的刻度牌（k25）、发圈的投影（k48）。**她从不走路、从不主动靠近。**
- 全片她的本体出现 **3 次**，每次 ≤ 2 拍：k13–k17（耳边）、k25（刻度 10）、k46 前后（折页把他夹住时露出的一角粉）。
- 色：亮 `#F2A8AA`／平 `#E58384`／影 `#A85660`／线 `#5A2A30`。

### 5.3 群演（灰纸）

- 3 个，只在纸城（k38–k42）出现，`#9A938B` 平涂、无眼、无脸，纸帽子会飞。
- 作用只有一个：衬托"城里那么多人，没有一个抬头看他"。**不许加第 4 个，加人先问。**

## 6. 画风卡（纸片立体书 · 硬约束）

**四件事同时成立才像这个画风：**

1. **两种尺度对撞**：真实的桌面（HDRI 光、木纹、软阴影、微距浅景深）＋ 平涂剪纸（饱和儿童书色、深棕墨线、奶白剪边、灰卡纸侧厚）。两者之间是**真实的镜头**——微距景深、接触阴影、纸片投出的是"剪影形"的影子。
2. **纸只有前后，没有厚**：任何"立体"都是几片平面卡纸 + 折线。楼 = 前后两片 + 一片三角形龙骨；人不倒角、不做圆柱。
3. **机关按真实顺序动**：立体书弹起是**由远及近**（离读者远的先起，延迟递增），合上反向。这条错了立刻假。
4. **纸的颜色是印上去的**：饱和但不荧光；墨线深棕；纸背是素纸；页与页之间换主色系（翻页 = 换色）。

**禁止**：霓虹/发光塑料感、纯黑描边、3D 圆角建模、溶解转场、纸面上出现真实照片、纸片"软体"变形（纸只会折、卷、撕，不会像橡皮一样扭）。

**镜头语言（本片只用这 6 种，每种都用满）**

| 镜头 | 用在哪 |
|---|---|
| 贴书脊微距横移（眼平、浅焦） | 开场、纸城横移、结尾合书 |
| 拉成 3/4 俯视整页 | 每次换页、看清机关 |
| 从人高处下降推入书页 | 只用在两次：进副歌前、结尾回书 |
| 正打脸推近 | 他"够不到"的四个瞬间 |
| 从书里反打真实桌面（大虚焦） | k44 页边、k55 桌上纸带、k57 桌沿往下看 |
| 锁死机位看一个抽拉条 | k50–k53 四条纸带 |

**光的四条规矩**
1. **每一拍必须有一次亮度或色温变化**——机关的翻面、纸的翻转、台灯的晃、影子的长，都算。

3. 褪色（k41–k43）是**逐片**发生的：从远端楼群开始，一秒内扫到近端，只留下他。
4. 结尾不做白闪、不做淡出——只有"光退出画面"。

## 9. 镜头表 S00–S09

### S00 · 冷开场 0.00–0.70（0.7 秒 4 连事件）

- **0.00**：全暗。只有桌面上一粒**纸尘**悬在台灯的光柱里飘——画面里唯一的东西。
- **0.08（k0，底鼓第 1 声）**：极特写——书页边缘一个 **V 折"啪"地弹起**，纸尘被震开，画面抖 **2px**。
- **0.30**：镜头压低到书页高度，贴着书脊往前推；左右两侧的纸片从镜头前**擦过两次**（每次 3 帧），世界一点一点立起来。

## 12. 声音设计

- **层次 1（主）**：原曲，不动。
- **层次 2（纸拟音）**：每个机关一个声，全部可合成——翻页 swish、卡纸 thump、弹出 snap（短正弦扫频 + 揉纸噪声）、折/压痕、抽拉条 slide、纸人脚步（小tap + 揉纸）、绳子晃的 tink、书脊吱呀、合书闷响。
- **混音**：拟音压在人声之下（-18 dB 起），全部**避让人声起音**（每个拟音的头 20ms 淡入），只在 k61 那一拍把拟音推到最前（全场只剩他的呼吸纸声）。
- **留白的用法**：k1 与 k61 两处实测无底鼓，音乐本身的空就是留白，不额外加音效。
- **禁止**：电子 riser、whoosh 库音、低频轰鸣——这个画风里所有声音都得是"纸和木头"。

## 13. 技术硬约束

1. **纯函数**：画面只由 `t` 决定；随机一律 `hash(seed)`；不许 `Math.random()`、不许跨帧状态。
2. **纸片阴影 = 剪影**：每张卡纸都要 alpha 深材质，投影是剪出来的形状；薄片阴影要收紧 bias，否则一墙痤疮。
3. **景深手算**：`CoC = aperture × (1/focus − 1/z)`，螺旋采样，近景不糊远景；不用引擎自带 bokeh。
4. **色调映射用 Neutral**；ACES 会把纸的饱和推走。
5. **纸的"厚度"是错觉**：只有奶白边 + 灰卡纸侧厚（向下偏 2px）+ 剪影影；不许做倒角。
6. **弹起顺序 = 由远及近**（延迟随离读者距离递增），合上反向。这条错了整段假。
7. **转身用 `scale.x` 翻面**，不用 `rotation.y`（会看到白背）。
8. **页块与翻页**：翻页是多段条带的弯矩积分，不是一张平面转；页背要自发光贴图（否则背光时整页发黑）。
9. **字体子集化**：中文字集按本片实际用字重建，每次改字幕都要重跑。
10. **30fps 为主**；若改 60fps，帧数 920→1840，渲染时间约 ×2，机关过冲的 `back()` 参数需重调（30fps 下的过冲在 60fps 会显得软）。
11. **禁**：真实照片、溶解转场、纸面出现镜面反光、纸被"橡皮化"变形、人手入画。
