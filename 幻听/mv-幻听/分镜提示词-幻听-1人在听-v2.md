## 1. 一句话

他在一块深夜的桌面上守着一份双人歌单。她不在了，但音量会自己跳一格、「正在输入」会闪一下、通知会自己弹出——**他听见的每一声"她"，都是界面在替他幻听**。整首歌他把歌单一行行送走，最后打下两个字，等一个不会来的回复。

**视觉总原则：她的存在只走 UI 通道**——头像、标签、通知、输入状态、光标。她本人只完整出现两次（S02 拼出、S04 崩解），稀缺才值钱。

## 4. 世界设定

一块虚构桌面 OS（风格取「玻璃拟态 + 深夜靛」，**全部界面由本片自定义、内部自洽，每个按钮/标签见下表**），分辨率 1920×1080。

| 界面元素 | 规格 | 作用 |
|---|---|---|
| 桌面壁纸 | 暮色渐变（L3 前暖米紫 → L3 后午夜靛），像素雨丝、星星 | 天气与时间的第一布景 |
| 状态栏 | 顶栏：时钟 **22:47**（L3 翻暗时跳成 00:00）、音量、Wi-Fi、输入法 | 时间跳字是「入夜」的 UI 表达 |
| 播放器窗「幻听」 | 主窗 1180×720 居中偏左：左专辑卡（月亮封面）、右歌单 4 行 + 空行、底部进度条/播放控制 | 主舞台 |
| 歌单「我们的歌单」 | 4 行：《幻听》青 #4FC3F7／《晴天》黄 #F2CD37／《夜曲》蓝紫 #6C7BFF／《后来》橙 #F0703A，每行左侧粉色小标「她分享的」；列表尽头第 5 行「未命名」（空） | 「列表里的歌 随过往流动」的实体 |
| 成员胶囊 | 「我们的歌单 · **1人在听**」 | 全片题眼，S09 闪「2人」 |
| IM 窗「回声」 | 右侧 420×560：两句对话 + 「对方正在输入…」 | 她留下的最后一屏 |
| 通知横幅 | 右上滑入：『她分享了《晴天》』等 | 间奏的通知风暴 |
| 音量 popover | 音量图标弹层，滑块旋钮 | 她爬出来的门（S02） |
| Dock | 底部玻璃条 | 拉远揭底时才有戏 |
| 输入框 | 聊天窗底部 + KeyCastr 键显 HUD | 结尾 |

**三条硬规矩：**
1. **小人只站在真实 UI 的上边缘**——进度条、歌单行顶、音量滑轨、均衡器条顶、状态栏、Dock。所有站位按界面布局逐帧量出来，不许悬空漂浮。
2. **颜色住在内容里，不住在窗框上**：窗框铬色一律低饱和靛灰；鲜艳的糖果色只出现在歌单行、频谱、通知卡、粒子上——这是「色彩多样鲜明」与「高级感」并存的解法。
3. **镜头 zoom ≥ 1**：永远在屏幕内部运镜，拉远最多到「整块桌面 + 窗口浮在壁纸上」，不许穿帮到显示器之外。

## 5. 角色设定

### 5.1 主角（他）

| 项 | 规格 |
|---|---|
| 体 | 方盒像素身，陶土橙 `#D97757`（全片不变色，只随主题光压暗/提亮） |
| 栅格 | 与全部像素道具共用 4px 方格；位移吸附半格，走步进感 |
| 眼 | 8 种眼位：平视/左/右/上/下/瞪/眯/眨——**表演靠眼睛** |
| 动作库 | 站、走（换向翻面）、跳（预备下蹲→起跳拉伸→收腿→落地压扁+阻尼回弹+8-bit 落尘）、拖拽、伸手、贴玻璃、打字 |
| 待机 | 随拍点轻微一压一弹（呼吸落在拍上），不规则眨眼 |

### 5.2 她（粉色 clawd `#E58384`，矮 1 格）

- 只出现两次本体：**S02 从音量滑块里一块块拼出来**（每拍一块）、**S04 从脚底像素化崩解**（碎尘拼出点阵「幻听」二字）。
- 不许走远、不许说话、不许完整站立超过 2 拍——她永远"差一点"。
- 其余出场全是 UI 痕迹：粉色小标、灰色头像、通知卡、「正在输入」、光标。

### 5.3 光标 = 她的手（本片暗线，硬规则）

- 白色系统光标全片只出现 **4 次**：P04 悬停预览卡（她还在整理歌单）→ P18 按下月亮（她把夜色带给他）→ P61 结尾轻轻动一下（回应他的「在吗」）→ P63 黑场里停在输入框旁。
- **他的一切 UI 操作用像素手直接做，不用光标**——光标一动，观众就知道是"她"。全片不解释，结尾自明。

### 5.4 群演

无。全片两个角色。要加人必须先问。

## 6. 色彩与光（两段式 + 糖果内容色）

| 段 | 时间 | 主题 | 铬色 | 内容色 |
|---|---|---|---|---|
| 暮色 | 0–9.4s | 浅色主题 | 暖米紫壁纸 `#EDE6F2` / 窗 `#FBF7EF` | 歌单四行糖果色全开、频谱蓝紫渐变 |
| 夜 | 9.44s 起 | 深色主题（径向翻暗） | 午夜靛 `#10142B` / 窗 `#1B2138` / 玻璃 `#262E4D` | 糖果色保留但压暗 15%，频谱转深蓝，月亮出现 |

**色板**：主角 `#D97757`｜她 `#E58384`｜幻听行 `#4FC3F7`｜晴天行 `#F2CD37`｜夜曲行 `#6C7BFF`｜后来行 `#F0703A`｜频谱渐变 `#5A6BD8→#8A7BFF→#F2A0C0`｜粉粒子 `#F2A0C0`｜夜星 `#E8ECFF`。

**光的三条规矩**：
1. 每个事件必须有一次光变化（频谱重组、星星亮、胶囊变色都算）——否则只是在动，不是在演。
2. L3 的**主题翻转**是全片唯一的"世界级"变化，从月亮图标径向扩散 6 帧完成，不许加白闪。
3. 尾奏聚光定格：vignette 压四周，只亮正在播放卡——最后一次"高能"是**收**，不是放。

### S00 · 冷开场 0.00–0.74（牛逼开头，0.74s 内 4 连事件）
- 0.00：黑暗桌面上雨丝落下（像素雨）。**0.05**：第一颗雨点击在桌面，荡开一圈像素环——全片第一个声音比音乐先到。
- **0.30**：**光标（她的手，观众此刻不知）**滑入，双击桌面旧文件「我们的歌单.m3u」。
- **0.50**：文件图标炸成像素块，四角「啪、啪、啪」三声，播放器窗口组装成形。
- **0.74**：底鼓第 1 声——小人从专辑封面的月亮里爬出，正好**踩在窗口标题「幻听」两个字上**，标题被踩沉 2px 回弹。起唱「如今」与落地同帧。

### S01 · L1「如今一个人听歌 总是会觉得失落」0.70–4.60｜P00–P08
**在说什么**：一个人，守一份两个人的歌单。
- **P01 (bar1)**：频谱墙从窗底升起（蓝→紫渐变，一次成墙）；他落到进度条 0:00 端坐下。
- **P02**：他拖着自己 mini 头像爬上「正在听」成员槽——槽里另一个头像是**灰的**。
- **P03**：歌单从右滑出：行 1《幻听》亮，行 2–4 暗，粉色小标「她分享的」逐行挂上。
- **P04**：光标滑过《晴天》，行弹起预览卡：「睡前听这首 · 3-14」。
- **P05 (bar2)**：推近预览卡，背景 rack focus 虚化，日期 2026-03-14 微微放大。
- **P06**：他伸手摸卡上她的粉色头像——头像缩了一下（躲）。
- **P07**：一粒像素尘从他头顶飘落，频谱全体降一格。
- **P08 (bar3)**：拉回全景，右栏「评论 37」角标闪一下。
- 转场：无切，P08 拉镜带走。

### S02 · L2「幻听你在我的耳边 轻轻诉说」5.36–8.35｜P10–P17
**在说什么**：她的声音从界面里出来了，人也是。
- **P09 呼吸拍**：音量图标**自己**跳了一格（没人碰）——全片第一次"幻听"。
- **P10**：音量 popover 弹开，滑块旋钮变粉；一只粉色小手从旋钮里伸出来。
- **P11–P12**：粉 Clawd 沿滑轨一块块拼出（每拍一块，咔哒咬合），P12 头拼上、眼睛亮、频谱顶出小尖峰。
- **P13 (bar4)**：她完整落地在均衡器条顶——squash 回弹 + 8-bit 落尘。
- **P14**：她戴上比她还大的耳机凑近他耳边；他耳边浮起方块声波环（随人声振幅逐拍重组）。

### S03 · L3「夜色多温柔」8.92–10.28｜P17–P20

### S08 · L7「列表里的歌 随过往流动」23.92–26.85｜P49–P56

## 10. 动效与技术硬约束（living-screencast 铁律）

1. **像素栅格神圣**：小人、道具（耳机、粉块、气泡豆）、尘、星星共用一个方格栅格，边缘锐利；位移吸附半格。UI 是高分辨率矢量——两套分辨率的对撞就是本画风。
2. **站位全部实测**：小人只站在真实元素的上边缘（进度条、歌单行顶、滑轨、均衡器条、状态栏、Dock），位置每帧由界面布局量出，不许手摆坐标、不许漂浮。
3. **因果律**：小人的每个动作必须触发一次真实界面状态变化（踩心→心满；拖头像→成员数变化）；每次弹窗/通知/菜单都按系统原生动画走，不发明界面没有的花活。
4. **运动模糊**：只在 whip-pan 时施加，且加在**未变换的包裹层**上（否则像素精灵会被拉糊）；慢速运镜保持锐利。
5. **纯函数**：画面只由 t 决定。随机一律 `hash(seed)`，禁止 `Math.random()`、禁止跨帧状态。
6. **声音**：底层是原曲（hi-fi 层）；拟音 8-bit 层——窗口组装咔哒 ×3、脚步、popover 弹跳、通知铃声（每条同音高）、键帽 thock、P58 上线音（比音乐低 12dB）。全部音效避开人声起音。
7. **禁**：真实截图、溶解转场、白闪（主题翻转和聚光都不许）、把光标交给小人以外任何人、镜内出现人手。
