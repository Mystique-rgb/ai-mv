## 一、这一版换了什么

上一版是「桌面 + 底部字幕 + 主角在界面里走位」。这一版把**歌词本身变成布景**：

**71 个歌词字排成一条横贯 18000 像素、上下起伏的长路，主角一个一个字往前跳。**
镜头跟着他跑，所以整片天然是一镜到底的横向行进。

三件事同时成立，是这一版的核心：

1. **字是台阶**——每个字有固定的世界坐标、固定的落脚时间、字下方一条朱色光台。
2. **人踩着字跳**——脚底永远落在"当前字"的上沿；两字之间是抛物线，落地压扁、空中拉长。
3. **每跳一次都有事件**——落地瞬间：字下沉 15px 并变朱红 → 冲击环扩散 → 笔画碎屑迸出 → 脚下扬尘 → 相机下压 + 抖动 + 变焦脉冲。

## 二、字的时间是怎么定的

`.ass` 只有整句时间（没有 `{\k}` 逐字标签），所以逐字时间是算出来的：

```
句内第 i 字：t = t0 + (t1-t0)·i/n
再吸附到八分音符网格（拍长 0.470s，锚点 1.45s → 网格 0.235s）
```

吸附之后步长会在 **0.235s / 0.470s** 之间自然跳动，于是跳跃节奏是「哒哒哒—哒哒哒哒哒—哒哒」，
而不是机械的等速。这是"踩着歌词"最关键的一步——73% 的音符落在八分音符上。

## 三、视觉语言

| | 还没踩到 | 刚踩中 | 踩过之后 |
|---|---|---|---|
| 字形 | 淡填充 + 细描边（轮廓） | 填实 + 朱红/金 + 外发光 | 实心，逐渐降到 60% |
| 位置 | 在原处 | 下沉 15px 后回弹 | 归位 |
| 光台 | 微亮 | 爆亮 | 回落 |

"空心 = 还没走到，实心 = 已经走过"，观众不用看字幕也知道进度。

**两套色**：0–9.44s 是纸与墨（米白底 / 深褐字 / 朱红踩中），9.44s 起径向翻暗成夜（深蓝底 / 米白字 / 金黄踩中）。
翻暗用 `clipPath: circle()` 从播放器专辑封面扩散，是上一版留下来的转场。

**界面降级为背景**：桌面和播放器只在开场（0–2.3s）和结尾（26.9s 后）出现，
中间几乎全隐，只留壁纸、频谱、时钟、月亮。字才是主体。

## 四、开场的 0.745 秒

- **0.00–0.30**：极近特写，第一个字「如」的笔画占满整个画面（z=6.4），从左侧缓缓滑向中心，机身带 2.5° 倾角。
- **0.30–0.70**：急速拉远到 z=2.1，界面在拉远过程中浮现（"原来是个界面"）。
- **0.05–0.745**：主角从 1180px 高处自由落体（`1-u²`，越落越快）。
- **0.745**：砸中「如」——字变朱红、巨大同心环、全屏闪白、相机下压。

## 五、结尾（27.06–30.64）

主角跳到一块悬在路尽头的聊天气泡上，打下「在吗」，**不发送**。
下方「对方正在输入」三个点，**前两个亮，第三个一直是灰的**。
相机在最后 2 秒缓慢推近（2.08 → 2.78），把这点停顿压住。

## 六、运镜

33 个机位关键帧，景别 2.0–3.2（一屏 3–5 个大字）。**主角在画面里的落点（sx, sy）是关键帧的直接参数**，
相机位置反算出来 —— 所以"他在画面左三分之一往右跑""他在正中推近"这类调度可以精确写在表里。

叠加三层：
1. 落地 kick（每跳一次）：下压 9px + 抖动 + 2.2% 变焦脉冲，指数衰减
2. 手持漂移：`sin(t·0.8)·2.2px`
3. 甩镜运动模糊：按相机速度触发 `feGaussianBlur`，上限 6/3（sigma，不是半径）

## 七、量化验收

- 逐帧灰度差中位数 **7.15**（上一版 2.15），静止段只剩 **28.73–29.33s 一处 0.6s**（"在吗"打完后的呼吸），是设计的一部分。
- 919 帧无黑帧，亮度区间 **15.0–230.5**。
- 字幕时间轴与 v2 完全一致（7 句），逐字吸附误差 ≤0.06s。

## 九、这一版踩到的坑

1. **界面视差不要用世界坐标差**。`translate(-(cx-960)*0.2)` 里 cx 是世界坐标（几千到一万九），
   一乘就是 1000+ 像素的位移，直接把 3320px 的壁纸拖出画外、露出 body 底色（表现为"半屏灰板"）。界面层要固定。
2. **壁纸必须不透明**。界面半透明化要用「UI 元素单独包一层 opacity」，不能让整层 `mbw` 变透明——
   否则壁纸跟着透，露出底色，暗场会整片发灰。
3. **`-webkit-text-stroke` 做空心字**在华文行楷这种细笔画上是成立的，但描边要 ≥1.5px，否则远看消失。
4. **裁剪（culling）要按字中心算**，不是按字底。因为字是「底边对齐」定位的，
   用 `c.y` 判断会把正在踩的那个字裁掉（表现为"人踩在空气上"）。
5. **影子是"踩"的关键**。没有投影时，主角在两个字之间看起来像在漂浮；
   加了落点投影（随高度缩小、变淡、超过 400px 不投）之后，跳跃高度立刻可读。
6. **自由落体用 `1-u²`**，不是 `1-easeOut`。`easeOut` 是"先快后慢"，正好反了，看起来像被吸下去。
