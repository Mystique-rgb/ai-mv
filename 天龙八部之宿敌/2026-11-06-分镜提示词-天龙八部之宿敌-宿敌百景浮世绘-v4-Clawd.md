## 1. 一句话

**这不是一部动画，是一本画集被人一页页翻过去——而画里的人已经被刻死在版上了。**

而这个"人"，是一个盒子。盒子有眼睛、有腿、会怕、会疼、会抬头看月亮——但它里面是空的。全片只有一只手是真正活的（在画外刻版、印版、卷画的那只）。Clawd 的所有表情，都是那只手刻上去的。

**Clawd 作为主角的三个红利**（不是妥协，是升级）：

1. **剪影即版**：Clawd 就是一个方盒加四条腿——这正好是"一块黑骨版"能刻出来的极限形状。三次副歌"同一块版重印"从设计变成了物理事实。
2. **无脸之脸**：两张竖眼缝 + 一个嘴，表情越少，观众投进去的越多。B3 只剩线时，它是一张空白的脸。
3. **小**：Clawd 天生是"风景里的小人"，跟浮世绘的名所语法（小人站在大风景里）严丝合缝。它越小，命越重。

**纪律**：陶土只属于阿宿，粉只属于粉煞。景物禁用这两色（灯笼用纸白、桃花用淡绯 `#D98C7E`、火用深朱）。

### 2.3 新增道具：菅笠 `kasa`

现有 `hat()` 里没有斗笠，需新增一支（照同一套画笔写）：

```
kasa：帽面 = 纸白平涂（washOp 255, bleed .02）；墨线 12 根放射编织纹（从顶尖到檐口，宽度 .5u，端部收细）；
      檐口一圈双墨线；直径 12u（比身体宽 2u），顶尖在 -13.5u；
      两根系带从檐下 3u 垂到体侧（只有斜戴时可见）。
参数：kasaTilt(-1..1) 倾斜；kasaBack(0..1) 挂背；kasaY 上下微调。
规则：kasaTilt 非零时，檐口最低点必须高于眼中心 1.2u 以上——不许压到眼睛。
```

### 2.4 表演系统（这是 v4 的核心）

Clawd 的表演只有六个通道，全部驱动自 `emotions(t, keys)`：

| 通道 | 参数 | 用法 |
|---|---|---|
| 眼缝 | `eyes` | normal / narrow / wide / sad / angry / squeeze / closed / look / shine / spark / x / swirl / shades / heart |
| 嘴 | `mouth` | flat / smile / frown / O / wobble / teeth / laugh / cat / smirk / tongue |
| 身体 | `sq`（挤压）、`dy`（离地）、`rot`、`dx` | 情绪的主载体：sad 是向下压扁，angry 是抖动，surprised 是拉长 |
| 手臂 | `aL` / `aR`（0 平伸，+ 举高，− 垂下） | 说话、指向、护身、放弃 |
| 饭盒嘴 | `lid`（0–1，仅正视图） | 上半身掀开——V65 爆线、V29 吞人 |
| 符号 | `emote` | ! ? !! sweat anger steam spark hearts zzz……**是画出来的符号，不是文字** |

**情绪脚本（全片主干）**：

| 段 | 阿宿的情绪线 | 粉煞 |
|---|---|---|
| P 前奏 | —（还没被刻出来） | — |
| A1 | neutral → confused → scared → determined | suspicious |
| A2 | hopeful → sad → proud → relieved | — |
| B1 | determined → angry → surprised → ko（裂开） | smug → mischief → surprised |
| 间奏 | 无主角（只有群演与景） | 一闪而过 |
| A3 | sleepy → cry → hopeful → love（4s） | — |
| A4 | sad → disgusted → ko → determined | — |
| B2 | furious → scared → cry → ko | furious → laugh（坏掉的笑） |
| B3 | neutral → relieved → smile → neutral | 同一条线 |
| 尾 | —（回到纸） | — |

**动作语言三条铁律**：
1. **不许补间**：所有动作 8fps 步进（`t8 = Math.floor(t*8)/8`），姿势只落在关键帧上。浮世绘的动是"换一张画"，不是"滑过去"。
2. **走路由腿说话**：`walk` 相位，四条腿对角成对摆；跑 = 相位×2 + 每步 dy 弹 0.4u。
3. **重音用 take**：每个鼓点上的情绪切换必须带 squash-stretch（`take` 参数），没有 take 的换脸 = 假。

## 3. 三大硬主线（锁定）

### ① 套版错位 0 → 8px → 0

| 段 | 错版 | 说明 |
|---|---|---|
| 前奏 | 0 → 0.5 | 造物未完成 |
| A1 / A2 | 0.5 / 1 | 几乎看不出 |
| B1 | 2 | 正常工艺 |
| A3 / A4 | 2.5 / 4 | 开始难受 |
| **B2** | **8（局部 30）** | 崩 |
| **B3** | **0** | 全片唯一严丝合缝 |
| 尾 | 0 | 不需要了 |

**Clawd 加成**：两个人的身体是同一个 `clawd()` 画出来的，所以"套准"不是美术去对，是**代码天然对齐**。B3 的 0px 只要把 `dip` 设成 0，两个人的轮廓就会精确重合——观众看到的是"原来你就是我"，不是"画得挺齐"。

### ② 同一块黑骨版，三次重印

| | 色版 | Clawd 的状态 |
|---|---|---|
| **B1**（62s） | 陶土 + 粉 + 一点深朱 | 一个陶土 Clawd，一个粉 Clawd，站得笔直 |
| **B2**（163.5s） | 深朱 60%+，粉被浸透 | 同一个 Clawd，颜色被红吃掉，只剩线 |
| **B3**（205s） | 全撤，只剩墨线 | 同一个 Clawd，一个空盒子 |

### ③ 纸是白

浮世绘不用白颜料。雪、浪、雾、空天，全是没印到墨的纸。"消失"不是淡出，是**画面被纸白淹掉**。Clawd 被雪埋掉时，埋它的不是雪，是"没印色的纸"。

## 4. 色彩：人色与事件色分离

| 类 | 色 | 值 | 用在哪 | 配额 |
|---|---|---|---|---|
| 人·主角 | 陶土朱 | `#D97757` | 阿宿身体 | 只在他身上 |
| 人·宿敌 | 胭脂粉 | `#E58384` | 粉煞身体 | 只在她身上 |
| 事件·红 | 深朱 | `#A8322A` | 血、印、火、灯笼、刀鞘 | B1 前每帧 ≤8% |
| 结构 | 墨 | `#2B2233` | 骨线、字 | 全片 |
| 天/水 | 普鲁士蓝 | `#1F4E6B` | 天、深海、夜 | 段主色 |
| 天/水·浅 | 淡蓝 | `#6E9FB5` | 远山、雾、水 | 大面积 |
| 春 | 淡绯 | `#D98C7E` | 桃花、衣（非角色） | A2 |
| 土 | 赭石 | `#9A6A3C` | 山、木、棺、土 | A4 |
| 草木 | 灰绿 | `#7B8A6A` | 松、竹、歪笠 | A2/A3 |
| 金 | 淡金 | `#C8A05C` | 星、灯芯、余火 | 全片 ≤6 次 |

**九段九主色**（"多样"靠段落换，不靠一帧里塞颜色）：白 → 靛 → 绯 → 陶土+粉 → 全色 → 靛白 → 赭墨 → 血红 → 纸白。

**B2 的红为什么更狠**：深朱 `#A8322A` 和陶土 `#D97757` 同属红橙族。红漫过来时，阿宿不会"跳出来"——他会**沉进去**，只剩墨线还看得见。观众会觉得"他被这件事吃掉了"，说不出为什么。这是换 Clawd 之后才成立的一层。

## 9. 实现（painted-animation 接入）

### 9.1 项目骨架

```
bash "C:/Users/79420/.workbuddy/skills/painted-animation/scripts/new_project.sh" D:/ai音乐mv/天龙八部之宿敌/clawd-mv --keep-demo
```

`src/config.js`：`bpm = 137.9`，`offset` 取第一拍（前奏第 1 拍 ≈ 0.22s，实测后填），`duration = 263.34`，`audio = assets/song.mp3`。

### 9.2 角色调用（每个镜头一行）

```js
// 阿宿：原色，斗笠挂背，两把刀在身侧
clawd(x, y, u, { view: 'q', flip: false, ...feel('determined', t8),
                 hat: 'kasa', kasaBack: 1, walk: t8 * 1.6,
                 armL: (uu, sw) => katana(uu, sw, { long: true }),
                 boilKey: 'asu' });

// 粉煞：tint rosy，歪笠，短刀
clawd(x, y, u, { view: 'q', flip: true, ...feel('smug', t8),
                 tint: 'rosy', tintK: 1,
                 hat: 'kasa', kasaTilt: .55,
                 boilKey: 'fensha' });
```

**关键点**：
- `t8 = Math.floor(t * 8) / 8`——人物一律 8fps 步进，镜头用真 `t`。
- `boilKey` 必须给（人物会进出画面），否则 `boilSeed` 按调用顺序漂移，人物会"抖"。
- **两把刀挂在 `armL/armR` hook**（arm space，x 沿臂向外），不是在 body 上画——这样抬手时刀跟着走。
- 群演：`noEyes`（新增开关，跳过 `eyes()`/`mouth()`）、`col: '#8A8078'`、`tint` 不给。

### 9.3 要改 `clawd.js` 的三处（小补丁）

1. **加 `pass` 参数**（`'both' | 'wash' | 'ink'`）：`wash` 时所有 `paint()` 的 `ink` 传 `null`，`ink` 时 `wash`/`fill` 传 `null`。这样套版错位只需两遍绘制：
   ```js
   const dip = misreg(t);                      // §3 曲线
   clawd(x - dip, y, u, { ...opt, pass: 'wash', boilKey: 'asu' });   // 色版，偏 dip
   clawd(x,      y, u, { ...opt, pass: 'ink',  boilKey: 'asu' });    // 骨线，不动
   ```
2. **加 `hat: 'kasa'`**（§2.3 规格）+ 参数 `kasaTilt / kasaBack / kasaY`。
3. **加 `noEyes`**（群演没有眼睛）。

### 9.4 浮世绘后期层 `printify()`

每帧画完后叠一层（在 `core.js` 的帧尾 hook 里）：

1. **纸**：暖白 `#F1E4C6` 底 + 长纤维（α .09）+ 四角微黄。
2. **木纹**：每个色块内部叠低频噪声等值线（`source-atop`），天空和水最重。
3. **马连擦痕**：模糊圆弧 + 锯齿条纹（α .06）。
4. **goma-zuri 飞白**：`destination-out` 小点（α .3）。
5. **画框**：粗 3.2px + 细 1.4px 双墨框，内缩 44/38px，外面米色装裱边。
6. **bokashi**：天空/水按列逐像素生成，不许 `fillRect` 条带。

### 9.5 渲染节奏

- 先渲 V00–V07（前奏 22s，528 帧）验风格，再分段推进。
- 每段渲完出接触表（每 2s 一格）肉眼过。
- Clawd 的 `paint()` 调用数要控：一个角色 ≈ 12 个 fill（body/4 腿/2 臂/眼/嘴/束带/刀），远景群演降到 4 个（body+4 腿合成 2 个形状，不画脸）。
