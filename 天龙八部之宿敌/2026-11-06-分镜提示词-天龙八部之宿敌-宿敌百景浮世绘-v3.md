## 1. 一句话

**这不是一部动画，是一本画集被人一页页翻过去——而画里的人已经被刻死在版上了。**

全片只有一个"真正活着"的东西：那只在纸上刻、印、卷的手。人物是印出来的，所以他们的命早就定了。观众要感觉到的不是"故事在发生"，而是"故事早就发生完了，我们只是在校对"。

## 2. 三大硬主线（锁定，改稿不得破坏）

### ① 套版错位（0→8px→0）——接「恩怨各一半」

浮世绘每种颜色是一块独立的版，手工套印，永远对不齐。错位量是贯穿 263 秒的隐性参数：

| 段落 | 错版 | 观众感受 |
|---|---|---|
| 前奏 | 0 → 0.5px | 完美（造物阶段） |
| A1 | 0.5px | 几乎看不出 |
| A2 | 1px | 隐约 |
| **B1** | **2px** | 能看出，像正常工艺 |
| A3 | 2.5px | 雪里更明显 |
| A4 | 4px | 开始难受 |
| **B2** | **8px（局部 30px）** | 崩了（色块互踩、红漫出边界） |
| **B3** | **0px** | **全片唯一一次严丝合缝** |
| 尾奏 | 0px | 不需要错版了 |

**B3 的 0px 是全片最高潮**：观众花了 200 秒习惯"对不上"，突然对上了——那一刻他明白「原来你也是我」，不需要台词。

### ② 同一块黑骨版，三次重印——接三次副歌

三次副歌 = 同一黑骨版三次重印。构图、机位、人物位置全部相同，只换颜料：

| | 色版 | 画面 | 真相 |
|---|---|---|---|
| **B1**（62s） | 靛青 + 胭脂粉 + 一点朱 | 正常的一幅画 | 恩怨各一半，对不上 |
| **B2**（163.5s） | 朱红占 60%+，粉被浸成血色 | 同一幅画，印坏了 | 染指江湖，红压过一切 |
| **B3**（205s） | 纸白——色版全撤，只剩黑骨线 | 同一幅画，只剩线 | 无人逃得过，连颜色都没了 |

### ③ 纸是白——接「无人逃得过宿命」

浮世绘不用白颜料。雪、浪花、雾、空天，全是没印到墨的纸。"消失"不是淡出，是**画面被纸白淹掉**。人被"没印色"吃掉——比黑场更冷。

## 3. 角色颜色编成（v3 新硬规则）

**规则一句话：主角选原色，第二个选粉色，需要更多角色就按顺序再变颜色。**

| 出场序 | 角色 | 颜色 | 色值 | 识别特征 | 用途 |
|---|---|---|---|---|---|
| 1 | **阿宿**（主角） | 原色 · 靛青 | `#1F4E6B` | 菅笠侧身立像，朱红腰带，刀身留白 | 全片唯一靛青衣，永不换色 |
| 2 | **粉煞**（宿敌） | 粉 · 胭脂 | `#CE5A70` | 与 A **同一套黑骨线**镜像 180°，灰绿歪笠覆面，双短刀 | 全片唯一粉衣，永不换色 |
| 3 |（若需第三人）| 赭石 | `#9A6A3C` | 待定 | 需用户确认后才上 |
| 4 |（若需第四人）| 灰绿 | `#7B8A6A` | 待定 | 需用户确认后才上 |
| 5 |（若需第五人）| 金（淡） | `#C8A05C` | 待定 | 需用户确认后才上，且金全片 ≤6 次 |

- **主角色永不借用**：靛青只属于 A，胭脂粉只属于 B，任何景物/群演不得使用这两色（靛青天改用淡蓝 `#6E9FB5`，粉花改用淡绯 `#D98C7E`——比角色色浅一档，保证人从画面里"跳出来"）。
- **颜色语义分离**：粉 = 人（B），朱红 = 事件（血、印、火、灯笼）。唱到"血红染"时染的是街和灯笼，**B 身上的粉不动**——直到 B2，粉被血浸透（粉 → 深胭脂 → 血红），这才是"他也脏了"。
- **群演**：灰墨剪影小人（高 55–90px），只有轮廓 + 一点灰平涂，没有脸，不上任何角色色。永远朝同一个方向走，从不回头（除 V54 集体停步）。
- 小人骨架统一用风格库 ukiyo-e demo 的 `traveler.js` 平面关节小人（重绘为役者绘造型），全片共用同一套骨线。

### 人物姿态（役者绘·見得）

浮世绘画人不画解剖，画**姿态**。每个重音用一个「見得」姿势卡在鼓上：

- **阿宿・見得**：右手按刀柄，左脚前踏，身体侧转 45°，头回望镜头。脸三笔——斜眉、细长眼、短横嘴，**不画鼻子**。
- **粉煞・見得**：双刀交叉护胸，重心后坐，头略低、眼睛向上看。唇一点朱。
- **核心设定**：A 和 B 是同一块黑骨版印出来的两个人。V20、V32、V80 三处必须让观众看清：两人的轮廓线可以严丝合缝重合。这不是修辞，是画面事实。

## 4. 风格卡（每个镜头必须满足）

### 4.1 版画本体

| 项 | 规格 |
|---|---|
| 纸 | 和纸，暖白 `#F1E4C6`~`#EDDDB8`，长纤维（α .09），边缘微黄，四角略深 |
| 画框 | 粗线 3.2px + 细线 1.4px 双墨框，内缩 44/38px；框外米色装裱边（比纸深一档） |
| 骨线 | 2.4–3px，变宽填充描边，两端收尖，宽度抖动 ±20–35%（低频） |
| 色块 | 平涂，**每块独立一块版**，带木纹 × 马连擦痕 × goma-zuri 飞白点（α .3） |
| 天空/水 | bokashi 逐像素生成，上缘按列低频噪声漂移 ±20–30px。**禁止 fillRect 条带** |
| 雾 | suyari-gasumi：长圆角平带，两端淡出 |
| 远层 | 淡、低对比、灰骨线或不画线；近层饱和、重骨线 |
| 印章 | 朱红 `#B5322B`，字从红里"刻"出来，边缘崩口，深底上用 `source-over` |

|---|---|---|---|

### 4.3 色彩多样鲜明：九段九主色

"多样"靠**段落级换主色**实现（段内不破上限，这是浮世绘本体，破了他就不再是浮世绘）：

| 段 | 主色组合 | 明度对比策略 |
|---|---|---|
| 前奏 | 纸白 → 墨 → 靛 | 极端：白↔黑 |
| A1 | 靛 + 淡蓝 + 纸白 | 冷高对比 |
| A2 | 淡绯 + 灰绿 | 暖春，全片最柔 |
| B1 | 靛 + 粉 + 朱点 | **三色对峙**（人色进画面） |
| 间奏 | **全色轮转**（十景十套配色） | 全片最花 |
| A3 | 靛 + 纸白 + 一点金 | 冷到极致 |
| A4 | 赭 + 墨 | 重坠 |
| B2 | 朱红过载 + 浸透的粉 | 全片最烈 |
| B3/尾 | 纸白 + 墨 + 唯一一点朱 | 极简回零 |

**"鲜明"的落地**：每段给 1 个**高亮点缀**（前奏的朱印、A1 的朱栏桥、A2 的桃花、B1 的粉煞、间奏的火、A3 的金星、A4 的朱棺、B2 的漫红、B3 的空印框）——9 段 9 个爆点色，段段不一样。

### 4.4 运动质感

- 印好的画大部分不动；**每幅至少 2 个活元素**（v2 是 1–2）。
- 人物/草木 8fps 步进（24fps 下每 3 帧换姿，只在 2–4 个预设姿势间切，**不做补间**）；雨、激流、火 12fps；镜头 24fps 逐帧。
- 印刷揭示：0.3s，对角马连擦痕噪声边，落下先滑 5–6px 再"咔"归位。
- 题签落下：淡入 + 短滑 8px（0.25s）。印章：scale 1.35→1（0.2s）+ 3px 震动。
- **一个运镜要读得懂至少给 1 秒**；低于 1 秒的切换只能是"撞"（硬切/爆发）。

### 全程高能的落地（v3 版）

1. **开场 3 秒法则**：0–3s 内必须有 3 次可察觉的变化（见 V00）。
2. **密度规则**：主歌每拍 **1–2 件**事件；副歌每拍 **2–3 件**；间奏每拍 **2–3 件**（G2+G5+G4 可同开）；落印那一拍只给 G8。
3. **双活元素**：每幅至少 2 个会动的东西，且至少 1 个是"有生命的"（人、鸟、狗、火），1 个是"环境的"（雪、水、雾、灯）。
4. **重复句升级**：三次副歌逐次加码（B1 工整 → B2 崩坏 → B3 归零），同句绝不原样再放。
5. **以静为爆点**：B2 满屏红 193s 之后，B3 全白 + 错版归零——减法本身就是最响的一声。保留三处静：V04 显影（俯视锁定 2.6s）、V70 刻线（机位不动）、V78 静止 **1.6s**（v3 由 2.6s 缩短，保爆点不减憋闷）。

### P · 前奏 0.00–22.30 · 从零造一幅画

> 全片最贵的一段。它回答一个问题：为什么画里的人逃不掉——因为他们是被刻上去的。
> v3：开头 3 秒 3 变化 + 走马灯钩子。

**V00 · 0.00–1.30 ·（无词）· 未印 · 纸白** ⚡v3改
- 画面：整幅空白和纸。左下角一枚朱印「宿」，刚盖上，印泥在洇。
- 事件（**3 秒 3 变化，全在前 1.3s 起头**）：① 0.22s 印章 scale 1.35→1 砸下 + 3px 震动；② 0.43s（第 1 拍）右上角第一根黑线划出 60px（带"刻"的沙沙质感——线边缘毛）；③ 0.87s 第二根线接着长；④ 1.30s 第三根线长完、切入 V01 刀口特写（硬切，撞在拍上）。
- 运镜：锁定。
- 注意：白纸只给 1.3 秒——够观众"咦"一下，不够他划走。

**V01 · 1.30–4.20 ·（无词）· 未印 · 木色+墨**
- 画面：梨木版横纹，凸脊浅木色、凹处深，刀口新，木屑挂在边上。V00 的线在版上是一条凸脊。
- 事件：**每拍一刀**（7 刀），每刀削出一片木屑飞出去（8fps 方块，1.5s 落定）；第 5 拍刀走到版心，"咔"一声闷响卡重鼓。
- 运镜：极缓推 1.00→1.06。
- 注意："刀"在歌词开始前 21 秒先刻进观众眼睛。

**V02 · 4.20–7.00 ·（无词）· 未印 · 墨黑**
- 画面：墨辊从左滚到右，凸脊变黑发亮。墨是 sumi 掺一点褐。
- 事件：辊每拍"弹"一下（2px）；墨色每拍加深一档（7 档）；**辊后拖一条未干的湿光**（第二个活元素）。
- 运镜：跟辊横移（右→左，定下全片卷轴方向）。
- 注意：辊的路线略斜——辊子是人手推的。

**V03 · 7.00–9.60 ·（无词）· 未印 · 纸白**
- 画面：一张和纸从上方垂下盖住整块版。落下一瞬画面全白，四角微翘，纸下透出一点墨色。
- 事件：纸落 3 段（每段 1 拍，8fps），落底"啪"卡重鼓；纸的下缘 3 个控制点让它"飘"。
- 运镜：不动。

**V04 · 9.60–12.40 ·（无词）· 未印 · 墨渐显**
- 画面：**隔着纸背看**。一只马连在纸背打圈擦，每擦一圈骨线加深一档。
- 事件：每拍擦一圈（7 圈）；第 5 拍**整幅画的骨线全部显形**——戴斗笠的人站在山脊上，侧对镜头。
- 运镜：俯视锁定，不动。全画面只有马连在转。
- 注意：全片最"高级"的一镜。命运在纸上浮出来，擦它的人不知道自己擦的是什么。

**V05 · 12.40–15.20 ·（无词）· 未印 · 墨+纸白**
- 画面：纸右下角被两指捏起向上翻，翻完——**第一幅完整的画**：戴斗笠的人侧影立在山脊，天空还没上色。
- 事件：翻 3 段（每段 1 拍），最后"唰"画全露；同时山脊上一缕云雾开始横移（第二个活元素提前进入）。
- 运镜：跟翻纸轻微上移 20px。
- 注意：第一个"哇"。**成品必须好看，否则前面白铺。**

## 7. 每个鼓点都有事件：八种发生器

不用手写上千条事件。全片只有八种可复用"事件发生器"，按拍/半拍/小节/段落头四级触发。逐幅分镜里写的"每拍…"就是调用它们。

| 号 | 发生器 | 触发器 | 参数 | 用在哪 |
|---|---|---|---|---|
| **G1** | **色版落位** | 小节头 | `stampLayer(reg=错版量, shift=[5,-4])`，0.3s 揭示，对角马连擦痕边 | 段落头、新景入画、加色 |
| **G2** | **卷轴格** | 每拍 | 画面整体横移 ±1/4 幅宽；短滑=急，长滑=慢 | 手卷段落（A1、间奏、V31/V67） |
| **G3** | **骨线生长** | 每拍 | 某条黑线延长 20–60px，两端收尖，宽度抖 ±25% | V01 刻版、V29 线冲入、V70 刻线、V79 合线 |
| **G4** | **8fps 步进** | 每 3 帧 | 人物/草木/动物换姿（只在 2–4 个预设姿势间切，不做补间） | 全片人物、灯笼呼吸、风中的松 |
| **G5** | **纸白粒子** | 每拍 | 雪/灰/火星/飞白点 1–3 个/拍；**有墨线勾边**，不是白圆点 | A3 雪、V61 灰、V37 火星 |
| **G6** | **印的呼吸** | 重鼓 | 印章 scale 1.00→1.02→1.00（0.15s）+ 印泥渗 1px | 全片所有印章 |
| **G7** | **bokashi 擦动** | 每 2 拍 | 天空/水渐晕上缘按列漂移 3–8px（低频噪声） | 夜景、海、雾 |
| **G8** | **画幅震动** | 落印/爆发/断笔 | 全画面位移 3–5px，指数衰减 0.25s；**永不回弹过冲** | V27 落印、V57 断笔、V65 爆线、V86 盖印 |

**v3 密度规则**：
- 主歌：每拍 **1–2 件**（G4 常开 + 一到两件别的）
- 副歌：每拍 **2–3 件**
- 间奏：每拍 **2–3 件**（G2+G5+G4 可同开）
- B3：每拍 **1 件**（事件以 G3 为主——减法段不是无事件段，是"只剩线在动"）
- 落印的那一拍：只给 G8，别的都停

## 8. 字幕规则：字幕就是题签，不是叠加层

字幕如果是浮在画面上的 UI，整部片的版画幻觉就毁了。字幕必须**印在纸上**。

### 形式
- 米色小纸条（`#F3E7C6`，比纸略黄），宽 = 字数×字号+60px，高 = 字号×1.5
- 粗墨框 2.6px + 细墨框 1.2px（**双线**，间距 6px）
- 纸条左侧一枚小朱印（28px，字用「宿」）
- 条内文字：**华文行楷 STXingkai**（`C:/Windows/Fonts/STXINGKA.TTF`），字号 54，墨色 `#1C1A18`，字距 +2，居中
- 位置：底部，纸条底边距画面下沿 88px；压在地平线之下，人物/地平线在其上方

### 动效
1. **落**：0.28s——淡入 30% + 从下滑 10px + 对角马连擦痕扫过（噪声边），落定"咔"归位（整体位移 2px）
2. **停**：时长 = 该句 srt 时长（**用已核对的对齐表，逐字起点做卡拉OK高亮可选**），最少 1.8s
3. **走**：0.2s 淡出 + 上移 6px（纸是纸，不是 UI）

### 关键：字幕的"纸"和画面的"纸"是同一张
纸条落上时下方有 2px 淡墨投影（它是叠上去的一张纸）；但"未印"的画面（前奏、间奏末）纸条**不能有投影**——它还没被印上去。

### 特殊处理
| 段 | 处理 |
|---|---|
| 前奏 V00–V07 | **无字幕**（没歌词） |
| B1 V20 | 题签被分割线切开，中间断 8px |
| B2 全段 | 题签**错版 8px**：纸条的双线墨框和朱印互相错开（连字幕都印坏了） |
| B3 全段 | 题签**没有朱印**（印还没落）——只有墨框和字 |
| V78 | 字幕提前 0.3s 出现、延后 0.5s 消失（配合静止） |
| 第 45 行「月下门童喟叹」（B3 段） | 该行逐字为插值估算，行级时间准确；字幕整行落下，**不做逐字高亮** |

## 10. 色彩弧与错版弧

```
时间 →  0    22   42   62   102  123  143   163   205   244  263
主色：  白 → 靛 → 绯 → 靛+粉 → 全色 → 靛白 → 赭墨 → 血红 → 纸白 → 纸白
饱和：  0    30   45   40     85    25     35    100     5      3    （%）
错版：  0    .5   1    2      2     2.5    4     8       0      0    （px）
粉衣：  -    -    -    ●      ●     -      -    浸透     线     -    （B 在场）
```

**两层接收**：进 B3 的第 0.5 秒，观众只感觉"怎么全白了"（饱和 100%→5%）；到第 3 秒（V70 那道缝），才发现"怎么对上了"（错版归零）。同一时刻的两个信息**不要同时给**——这 2.5 秒落差就是这一段全部的力量。

**反过来，B2 的 100% 饱和和 8px 错位是同一秒到达（163.5s）**——"崩"就是一瞬间的事。**加法同时给，减法分两层给。**

## 12. 引擎实现提示

引擎在 `C:/Users/79420/WorkBuddy/2026-10-31-19-32-52/styles/ukiyoe/demo/`：
`print.js`（纸/木纹/马连/色版/bokashi/刻线/揭示/题签/印）、`nature.js`、`wave.js`、`traveler.js`（小人骨架——**A/B/群演共用同一套骨线，只换衣色参数**）、`views.js`、`main.js`。

### 错版 = 一个参数
```js
// stampLayer(dst, src, reveal=1, reg=[0,0], shift=[5,-4])
// 全片只维护一个全局 dip：dip = MISREG[t]  // 按 §10 曲线插值
stampLayer(ctx, 靛青版, 1, [ dip, 0], [5,-4]);   // A 的色版
stampLayer(ctx, 胭脂版, 1, [-dip, 0], [5,-4]);   // B 的色版，反方向
```
**两个主角的色版错相反方向**——"各一半"才成立。

### 三次副歌 = 三次重印
`views.js` 每幅画的 `paint()` 接受 `paintSet` 参数。B1/B2/B3 调用同一个 `paint()`，只换 `paintSet`：
```js
paintSet.B1 = [indigo, paleBlue, rouge /*粉*/, beni];
paintSet.B2 = [beni, beniDark, soakedRouge /*粉被浸成血*/, sumi];
paintSet.B3 = [];   // 空数组 = 只印黑骨版
```
"同一块版"是代码层面的**同一次函数调用**，不靠美术去对——天然一模一样。

### 每拍事件
```js
const BEAT = 0.4348, BAR = BEAT * 4;
const g = (t, every) => Math.floor(t / every);
// G2 卷轴格
camX += (g(t, BEAT) - g(t0, BEAT)) * W * .25;
// G8 震动
const shake = (t, t0) => Math.exp(-(t - t0) * 9) * 5;
```
**禁止 `Math.sin` 做呼吸**——所有周期运动按 `beatIndex % n` 取整切换，保持步进感。

### 性能
- 每幅画的静态部分预渲染离屏 canvas 缓存一次，每帧只 `drawImage`。
- 只有活元素（雪、水、火、人物）逐帧重绘，限 8/12fps。
- 目标：1920×1080 @ 24fps，5 workers，全片 6320 帧，25 分钟内渲完。
