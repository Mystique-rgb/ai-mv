## 六、产线映射（v4 新增/替换资产）

```js
// rig v2：60 格半写实（1 格 = 像素层 2px，rig 净高 120px）
fig(c, cx, footY, S, o)      // o = {who, pose, view, ex(E1-E6), light:'gold'|'cool'|'none', pad}
face(c, ox, oy, u, o)        // 全片唯一脸数据（60 格 rig 与大块特写共用，硬约束）
                             // o = {who, ex:'E1'..'E6', tear, star, back}
goldChain(c, cx, footY, S)   // H1 金边链全路线（发斑→脸缘→肩线→臂→裤线→鞋→地面斑）
lightSpot(c, x, y, k)        // H2 面状光斑群（禁竖条光路）
poles(c, n)                  // 电线杆剪影（杆+横担+绝缘子）+ 电线 5 条垂弧
rainCoarse(c, t, n)          // 粗颗粒雨 1×3~4 格
```

**硬约束（v2 五条 + v4 三条新增）**

1. 文字全走 1920 高清层（行楷字幕 / 点阵 HUD）。
2. 手机镜与菜单镜 `cam:false`；像素层不画假文字。
3. 切点取早不取晚（24fps 早 13ms）。
4. **（H1）金边链是"一条链"**：同一镜内链路完整（可断续、不可缺段）；镜间方向随光源跳变合法。
5. **（H1）60 格 rig 与大块特写共用 face() 脸数据**——蘑菇头包脸形态在两种尺寸下必须一致。
6. **（H3）表情只走 E1–E6**，E6 泪仅 SH31 一次；表情特写镜先渲单帧样张过目再进全片（流程闸门）。
