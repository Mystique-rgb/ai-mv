## 一、一句话故事

> **她走后的第 163 个晚上，他又打开那款自己做的游戏。游戏里的一切都和那一晚一样——她只在过场动画里，等他看完就消失。**

游戏是他做的：车站、雨街、天台、那间出租屋，全是 2018 年 8 月 21 日 21:37 那一晚的复刻。
他把她做成了**过场 CG**（能看，看多少遍都行），却做不出一个**能回应他的角色**——角色表第二格永远是 `?`。
他每晚读档重打一遍，看完那段过场，然后对着空位说话；
真正能联系到她的地方只有一个：手机里那个再没亮过的微信。

第 163 次，他终于按了「退出」。

## 二、世界观语法（全片不变的五条）

| 规则 | 内容 | 画面上怎么落地 |
| --- | --- | --- |
| **游戏 = 记忆** | 场景全部是 2018-08-21 21:37 那一晚的复刻，现实里只剩手机 | 游戏内一切偏蓝紫；手机界面偏暖白（唯一"活着的"东西） |

## 三、角色与道具

### 他（唯一贯穿人物）
- 剪影级特征：深蓝卫衣（`#2A3450`）+ 暖白内搭 + 短发 + 右手始终握着手柄
- 表演：坐 / 躺 / 走（4 帧腿部交替）/ 抬头 / 伸手 / 按
- 关键：**他的脸永远半张在暗部**，只有手机屏的反光打亮下颚——他不是在被人看见，是在被屏幕照

### ★她（本版露正脸，5 个出现点）

| 项 | 设定 |
| --- | --- |
| 发 | 黑长直，中分，发尾齐肩（40px 角色上占 6px 宽，`400px` 缩图仍可分） |
| 衣 | 淡紫外套 `#B9A9D6` + 玫瑰红内搭 `#E8556D`（全片唯一"人间颜色"） |
| **剪影级标识** | **左侧耳后一枚金色小星星发夹**（`#FFD166`，3×3px，全片唯一金色小物件）——手机背面那颗贴纸就是从这上面撕下来的 |
| 眼 | 垂眼 + 笑时先弯；`48px` 高下仍可读（资产库实测） |
| 嘴 | 全片 3 种：说话（SH12）、笑（SH11）、闭着（SH13） |
| 出现点 | ①SH11 回忆贴贴纸 0.9s（侧脸转正脸 + 笑）②SH12 并肩说话（侧脸）③SH13 靠肩闭眼（**正脸特写**）④SH15 闸机后**回头 1.3s**（正脸）⑤SH22 镜中浮出的脸（正脸，但边缘是像素噪点＝不是真人） |
| 其余 | 微信头像（SH09/SH10/SH36）用她 32×32 的像素正脸小图 |

> **露脸的代价与补偿**：她一旦有正脸，观众就会期待"她和他同框"。所以本版把每次同框都盖上 `▶ 过场 CG` 的章——看得见她，但碰不到她。这比不露脸更疼。

| 道具 | 出现 | 承担的歌词 | 下场 |

## 四、色板与画风卡

| 族 | 色 | 用途 |
| --- | --- | --- |
| 暗底（4 色） | `#0E1220` `#1A2133` `#2A3450` `#46527A` | 夜空、楼群、墙面、地面，全部压在同一明度带 |
| 主体（2 色） | `#F3E7D3` 暖白 · `#FFD166` 暖金 | 他的内搭 / 唯一光源（台灯、手机屏、站台灯） |
| 她（1 色） | `#E8556D` 玫瑰红 + `#B9A9D6` 淡紫 | 内搭、外套、头像、闸机里那道背影 |
| 功能（2 色，只用于状态翻转） | `#C8463C` 红 · `#5FD3C4` 青 | "已过期""连接失败""存档成功" |

- **禁纯黑**，最暗处用 `#0E1220`
- 渐变一律 Bayer 抖动，无 alpha 过渡
- 每场景**只留一个暖光源**（台灯 / 手机屏 / 站台灯 / 月光）
- 主体必须比背景亮**两档**，靠 `spot()` 压暗四周，不靠占屏面积
- **她的脸必须比背景亮三档**（暖白肤色 + 玫瑰红内搭做领口锚点），否则在暗底游戏世界里认不出

**五条硬约束（产线经验，别踩第二次）**

1. **所有文字走 1920 高清层**（HUD / 字幕 / 微信文字 / 菜单 / `▶ 过场 CG` 标记），320 层只画场景与手机壳——320 层写字放大 6 倍必糊。
2. **手机镜与菜单镜必须 `cam_hd:false`**：相机推拉只作用于像素层，HD 文字跟不上。
3. **像素层不要画假文字纹理**（车票印刷线、菜单条纹），会穿过 HD 文字变成虚线杂纹。
4. **切点取早不取晚**：24fps 下目标帧落两帧之间时，早 13ms 比晚 28ms 跟手（实测）。
5. **她的正脸必须单独渲一版**：40px 角色上五官只占 8×10px，正脸特写（SH13/SH22）需要 `z≥1.4` 且眼/嘴在 320 层按 1px 级绘制，否则放大后是糊块——参照资产库"描边跳过 `w*h<=2`"的已知坑。
