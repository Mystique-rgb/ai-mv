## v6 相对 v5 改了什么（转场 + 声音）

### 1. 转场机：真"劈"（招牌动作）

v5 的转场其实是"扫一层色盖过去"（`P.sweep/sweepV`），劈只画了一道缝，两半没有位移。v6 重写为 **GL 裁剪（scissor）两半错位**：

- `flush()` 新增全局上下文 `TR`（转场）与 `SHIFT`（相机整体偏移）。
- **劈 `split` / 竖劈 `vsplit`**：上一镜整幅**重画两次**，每次用 `gl.scissor` 只留一半、相机反向错位 `s`，裁窗跟着缝口走（左窗 `[0, 960-s]`、右窗 `[960+s, 1920]`）。两半是真的在画面上滑开，**缝里露出的是下一镜本身**，不是一块颜色。
  - 位移曲线 `s = 1180·k^1.9`（竖劈 760），起手慢、后段加速出画。
  - `seamFX()` 覆盖缝口：露出的画布层（不等距、长短不一的碎刀，故意跳掉 18% 破"拉链感"）、颜料厚度的暗边、缝口亮刃、起手 0.16 s 的白闪。
- **刮 `scrape`**：上一镜切六条横带（裁窗），同向但**每条速度不同**地拖走，像一刀刀把颜料铲掉；`smearFX()` 叠细长刀痕拖影。
- **甩 `whip`**：`SHIFT` 给整镜相机加偏移——旧镜整体甩出、新镜从另一侧滑入（真位移），`whipFX()` 叠沿运动方向的速度线。2.19 s 以后、1.31 s 的是竖向甩。
- **同形切 `match`**：硬切 + 一个扩开并消散的环/带，把两镜的"同一个形状"接住（海平面 / 瞳孔 / 星野 / 纸船）。
- **盖 `cover`**：保留 `sweep/sweepV`，**全片只剩 31.60 s 一次**（黑压下来）。

### 2. 音效层：每次重涂配一声调色刀刮擦

新增 `tools/sfx.mjs`，**不依赖任何库**直接合成 16-bit WAV（带通扫频噪声 + biquad + 颗粒调制 + 软削波）：

| 声音 | 做法 | 用在哪 |
|---|---|---|
| `scrape` | 噪声过 2.2 Q 带通（2800→1400 Hz）+ 37/61/97 Hz 不规则颗粒调制 | 刮开、刮走、颜色推开 |
| `crack` | 10 ms 脆响 + 100→52 Hz 闷击 + 322 Hz 低体 + 刮尾 | 每一次"劈" |
| `whip` | 420→2900 Hz 带通风声 + 2800→620 Hz 反向层，sin^1.5 包络 | 甩镜头、火箭升空 |
| `shing` | 2085/3142/5210/7410 Hz 衰减分音 + 5.5 Hz 微颤 + 钢噪 | 切瞳孔、睁眼、彩虹 |
| `splat` | 300→70 Hz 俯冲正弦 + 760 Hz 低通湿噪 | 砸进海、粉花炸开、梦散 |
| `boom` | 74→34 Hz 次低 + 420 Hz 低通 + 90 颗随机爆点 | 43.00 花火 |
| `pop` / `thud` / `longscrape` | 星点亮起 / 黑幕压下的闷响 / 5 段鼓包的 1.6 s 长刮 | 点星×4、31.6、52.0 收尾刮天空 |

共 30 个事件，时刻与转场/爆点逐一对应，混成一条 55.28 s 单轨后与音乐 `amix`（音乐 0.90，`alimiter 0.95`）。成片峰值 −1.9 dB，无削顶；23.3 s 处 4 kHz 以上高频能量比纯音乐段高 7.8 dB。

## v6 仍然存在的不足

- **劈的副作用**：如果前后两镜都有居中角色（如 3.34 s），缝开的一瞬会出现"三个小人"（左右两半各半个 + 缝里新的一个）。这一处靠可接受度最高的角度切的，换别的机位会更明显。
- **刮会切断人物**：横带切过角色时，头身会短暂落在不同带里（0.3 s 内），读作"重影"。
- **甩的读感依赖内容差异**：两镜色调接近时（1.31 s 前后都是深蓝），主要靠速度线撑。
- 云边缘仍有笔触阶梯（长笔触在大画幅上的固有现象），静帧可见、运动中不明显。
- 灰人潮仍偏"兜帽剪影"，细节不如主角。

## v5 相对 v4 改了什么（构图语言 + 动作 + 四个短板）

1. **背景笔触方向跟景走**（不再是"横纹纸换颜色"）
   - 新增 `nightField()`：夜空 = 少量斜向大笔打底 + 420 颗星尘小点，把"横纹"打散成"颗粒"（SH28/SH29）。
   - `sky()` 加 `ang` 参数：天可以斜着铺；中层取色范围从 ±22% 收窄到 ±9%，修掉了天上那道深色划痕。
   - 海保持横向大刀；峡谷保持纵向崖壁刀；沙滩加横向干刷痕。
2. **云有体积**：`cloudPuff()` 重写 —— 6 个大圆刀叠出中间高两边低的团块，加底部暗芯和顶部亮边，不再是一根根横向白条。
3. **彩虹不再是扇形**：`rainbowArc` 加 `a0/a1` 弧段参数，圆心移到画面外，弧真正横跨全幅。
4. **瞳孔镜头重做**：粉色虹膜用 10 圈同心刀铺满盘面，海/沙滩/花/小人画在盘上，外圈一道深粉收边。溢出的笔触落在粉色上，反而更像"瞳孔里长着世界"。
5. **"睁眼"改成整张脸**：按 Clawd 自己的比例（宽 10u、高 6u）放大头部，5 道大横刀叠出上亮下暗，右暗左亮压出体积，加眉骨暗、鼻影、腮红、唇；眼睛用单刀椭圆，里圈金虹膜 + 星点 + 高光。睁眼那一下光从眼里溢到脸上。
6. **人物动作**：腿改成对角步态（对角腿同相、幅度 ±0.58u，带倾角），走路/奔跑加身体起伏；伸手前沉肩下蹲（SH15）；跳之前下蹲蓄力、腾空拉长、落地压扁过冲（SH24/SH25）；举手时手臂随高度伸长，够东西才够得着。
7. **结尾重做**：拉远后一直停在"画布挂在画架上"的空间里，一刀从右往左把天空刮掉露出底料和刃口，最后只剩左下角一点粉（带三层光晕）。
8. **顺手修的**：SH24 的"梦"原来是放射风车，改成外雾+主体+亮芯+下滴的颜料团；脚下的路原来是一根黄柱子，改成 46 段横向色带向后收窄并带弯；SH15/SH16 的沙滩补了远海、地平线和沙面质感。

## 仍然存在的不足

- 23.3–23.5 s 有 0.17 s 近黑（SH21 铲黑前的蓄力拍），是设计中的停顿，不是渲染错误。

- 瞳孔里的海是矩形笔触块，边缘不是圆形——靠虹膜盘遮住了大部分。

## v4 相对 v2 改了什么（三层笔触铺开）

1. **新增 `brush3.js`**：`layerPlane`（大平面 40–60px）/ `layerMid`（中笔 15–28px）/ `edgeRun`（小刀 3–7px）/ `knifeBlade`（刀片：刀身+亮面+刃口）/ `crackOpen`（劈开的裂口：内部分层+翻卷边缘）/ `paintDrop`（颜料滴：主体+细颈+高光+透光）。

## v2 相对 v1 改了什么

## 与分镜词的差异

分镜词里写的 91 个鼓点事件，实际实现按"镜头级事件 + 景内动效"落地，没有逐拍做 91 次显式切换——引擎每帧重画，景内运动（浪、雨、星光、云）本身就连续在动。开场一刀、点星每半拍一颗、花火爆开这三处是严格踩拍的。

## v6 附加：调色 + 9:16 封面

- **无字幕帧**：`film.js` 的 `frame()` 末尾加了开关，`still.mjs --q "nosub"` 即可出干净底图（封面用）。
- **调色强度（ffmpeg eq，注意方向）**：`eq` 的 `gamma` 是 `pow(x, 1/gamma)`，**gamma > 1 才是提亮**（1.22 让平均亮度 44.5 → 56.5；一开始写 0.92 反而更暗，白试一轮）。
  - 成片：`eq=gamma=1.22:brightness=0.01:saturation=1.12:contrast=1.03`，CRF 19 重编码，音轨 copy。
  - 原因：夜空底子本来就压得深，纯 `brightness` 提不动中调（只 +1.5 级，肉眼无感），必须走 gamma。
- **封面**：`寂寞烟火-封面-9x16.jpg`（1080×1920）。构图＝顶部标题（华文行楷 176pt）+ 中间 1080×1080 方形画面（从 1920×1080 里 `crop=1080:1080:420:0` 取烟花中心）+ 底部歌词与小字；背景是同一帧放大虚化压暗，顶部叠 120 级 alpha 渐变保标题可读；底部留白给抖音按钮区。
