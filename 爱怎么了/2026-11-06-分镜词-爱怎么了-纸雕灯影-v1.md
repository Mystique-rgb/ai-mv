## 2. 立意与母题

**故事**：分手后的一个晚上，他在这间房里收拾东西。房间本身是一盏纸雕灯——每一层纸是一段时间。每收起一样东西，就有一层纸被抽走。她一直在，只是永远站在他后面那一层。

**母题（全片最重要的一条规则）**：
> 影子是唯一能跨层的东西。人的身体被纸隔开，影子可以落在同一层上。
> 所以全片所有的"靠近"都不靠移动身体，靠**让影子重叠**；所有的"离开"都不靠走远，靠**抽掉她那一层纸**。

**三个大时刻**（画面本体发生改变，不是闪白震动）：

| # | 秒 | 记谱 | 事件 |
|---|---|---|---|
| A | 6.08–6.70 | B2+2.9 | 纸刀落下，把"两个人"的那张纸从中间切开 |
| B | 27.50 | B8+3.7 | 她所在的那一层被整片抽走，露出后面的夜空 |
| C | 41.72–43.28 | B13 | 风灌进箱体，所有层片向上飞，变成雨 |

**结尾与开场押韵**：开场灯已经亮着（我们从中间进入）；结尾灯一层层灭，最后只剩窗上一点光，然后回温 0.5s。

## 3. 角色卡（Clawd，painted-animation 内置小人）

两个角色共用同一套骨架与表情，只靠 `tint` 区分——这是全片唯一的"人"。

| | 他（主角） | 她（第二角色） |
|---|---|---|
| 配色 | 原色，**不加 tint**（`PAL.clay` 橙棕 #C86B4A 系） | `tint:'#F79AC0', tintK:1`（粉） |
| 层位 | 第 4 层（房间层，靠前） | 第 3 层（他后面一层，永远隔一层纸） |
| 尺寸 | 中景 u≈22，特写 u≈45–60 | 中景 u≈18，剪影时 u≈12 |
| 弧线 | sad → 麻木 → 慌乱 → 麻木 → 接受 | 亮 → 半透明 → 褪成纸白（tintK 1→0） |
| 消失方式 | 不消失 | **tintK 从 1 慢慢降到 0**，最后与纸同色，光影里只剩轮廓 |

**能用到的表情名（必须用引擎里的真名，不许自造）**：
`neutral` `sad` `cry` `confused` `thinking` `bored` `hopeful` `surprised` `scared` `nervous` `dizzy` `relieved` `love`

**规则**：
- 表情只走 `emotions()` 切换，不许换脸贴图；
- 转身必须走 `turn()` / `spinView()` 的绘制关键视角，不许 3D；
- 他的手臂动作（`aL/aR`）是唯一"表演器官"——伸手、抓空、张开，全片反复用这三个动作做呼应；
- 她全片**没有一句台词级的表情变化**，只有亮度和透明度的变化。她是光，不是人。

## 4. 画风卡（纸雕灯影 paper-lantern）

> 借自 lemo-opuscar `styles/paper-lantern/STYLE.md`，只借画法，不搬它的样片场景。

### 4.1 物理设定

- 每一帧都是**一件实物**：一个浅盒子（360×640×160 mm 竖版），里面平行插着 6–9 张剪纸。
- 盒内只有三样东西：**纸层**、**透过纸的光**、**影子**。
- 层深 z：天空 −140mm → 前景 0mm；相机 z ≈ 300–560mm，fov 26°。
- 每张纸：单色平涂 + 纤维纹理 + **顶边暖色描边** + **底边暗带**。后层亮而透，前层暗而实——**这个明度阶梯就是景深**。

### 4.2 光

- 唯一光源在箱体背后，暖色 `#ffb862`（主歌）/ `#ffd080`（回忆）/ `#9fb4d8`（副歌冷白）。
- 光透过纸有**云状斑驳**（纸浆纹理），越近光源越亮。
- 窗、灯、月亮是**打穿的洞**，会"烧"起来并有 bloom。
- 顶光给每层投**软影**到后面那层——这条不许关，关了就不像真纸。

### 4.3 运动法则（这是本片最容易被做坏的地方）

- 所有东西都是**棍子上的纸**：平移、绕支点旋转、沿单轴从 0 展开（"写出来"）、点亮。
- **禁止**：挤压拉伸（squash & stretch）、形变、弯曲、鞭甩镜头、数字变焦、3D 推拉。
- 关节小人 = 身体纸片 + 独立肢体纸片，**只能转，不能弯**。
- 光的变化是最大的动效：光源 → 各层透光率 0.4s 错峰 → 窗亮 → 闪烁 `1+.06sin(7.3t)sin(3.1t)`。
- 硬动作（切、抽、砸）**必须落在唱出来的那个字上**（见 §1.3）。

### 4.4 竖屏适配

引擎默认 1920×1080 横版，本片改 **1080×1920**：箱体占画面 78% 高、上下留 11% 暗场；前景窗框压到最外，纵深方向不变。镜头词汇不变，但"横向 travel"在竖屏里改为**纵向 tilt 穿过层片**，视差效果一样。

## 7. 逐句分镜（23 镜）

> 每镜字段：**时间 / 歌词 / 画面 / 镜头 / 表演 / 卡点 / 出**。
> 画面描述里出现的每个物件都是"一张剪纸"，不是 3D 模型。

### 镜 01 · 0.24–3.30 ·「收拾了行李 整理着包裹」

- **画面**：房间层。他跪坐在一只大开的纸箱前，从右边把衣服（薄纸片）一件件折起、压平、放进箱子。箱子是画面里最黑的一块（前层几乎全黑）。背后窗洞透出暖光，把他的手影投在箱口。
- **镜头**：近正面 `slow dolly in`，u 18 → 24，全程 3.06s，速度恒定（不许加速）。
- **表演**：`sad`。低头，`aL` 随每拍抬落；折衣服时 `sq` 微小（纸的硬度感，不是挤压）。
- **卡点**：0.24 收 → 0.95 拾 → 1.81 折 → 2.68 入箱。**每拍一件衣物落地/入箱**，纸片落定有 0.1s 回弹（纸的回弹，不是弹簧）。
- **出**：镜头继续推进，直接切。

### 镜 02 · 3.62–6.70 ·「从形影不离到轻易的割舍」

- **画面**：`dolly out` 拉开，露出整间房：左边他的箱子，右边墙上贴着**一张纸，纸上并排剪着两个小人（他 + 她）**——这是全片第一次出现"两个人"。唱到「割」(6.08)，一把纸刀从画面上方落下；「舍」(6.40) 刀切下去，那张纸从中间裂成两半，两半各自向左右滑开 3cm，纸边翻卷。
- **镜头**：3.62–6.30 `dolly out` u 26 → 15；6.30 硬切到 **top-down layer stack**（俯视那张纸），刀落。
- **表演**：他站在左下角，抬头看刀，`surprised`（0.8 起）→ 刀落下时 `scared` 0.3s → `sad`。
- **卡点**：刀落 = 「割」6.08；切开 = 「舍」6.40；两半滑开的最后一格落在 B2 小节末 6.94。
- **出**：切（刀口还在画面里就切）。

### 镜 03 · 7.58–10.55 ·「或者说 我们的爱怎么了」

- **画面**：裂开的两半纸浮在中间层，裂缝里能看见后面的夜空（深蓝 + 散点星孔）。他在裂缝左边，她在右边，两人隔着那道缝对看。缝在慢慢变宽。
- **镜头**：`rack focus`——先聚焦前景的他，唱到「我们」时焦点沿 z 轴移到她身上（4 层，各 0.15s 错峰），她抬头。最后 0.3s 焦点又回到缝中间。
- **表演**：他 `confused`（歪头，`rot` 0.1 缓慢摆）；她 `neutral`，只有眼睛动。
- **卡点**：7.58 「或」焦点起移；8.72「我」对焦到她；10.03「么」——**灯暗一档**（光从 100% 降到 65%，0.4s stagger，先暗前景后暗后层）。
- **出**：solved into B4 的黑（镜 04 从近乎黑起）。

### 镜 04 · 10.46–13.92 ·「（器乐，无字幕）」

- **画面**：几乎静止。他保持跪坐，低头，一动不动。房间的层片从左到右一片片变暗（0.4s 错峰），只剩窗洞那一点暖光和他手边一小块还亮着。
- **镜头**：`locked frame`，只有光在变 + 0.6mm 手抖微漂（让画面"活"着，不是死帧）。
- **表演**：`bored` → 11.5 起 `sad`，肩膀（`sq`）缓慢下沉 0.02。
- **卡点**：每拍熄一层的 1/4 亮度；B4 末（13.92）只剩窗光。
- **出**：13.92 光重新亮起，色阶在同一帧切到金（`dolly in` 已经开始）——用**光的变化做转场**，不用叠化。

### 镜 05 · 14.15–17.00 ·「细数着我们的过往」

- **画面**：色阶已是回忆金。他拉开第三层抽屉，抽出一叠照片。照片是薄纸片，**沿单轴从 0 展开**（"写出来"），每张上面都是两个小人——同一间房、同一个窗、同一天。
- **镜头**：**top-down layer stack**，俯看抽屉内部（像工匠看自己做的盒子）。相机不动，靠照片铺满画面。
- **表演**：`thinking` → 翻到第三张时 `sad`；手指（`aR` 0.9）一张张拨。
- **卡点**：14.35 / 15.22 / 16.08 / 16.94 —— **每拍一张照片展开**，展开方向交替（左/右）。
- **出**：切（照片还在半空）。

### 镜 06 · 17.18–19.30 ·「想到又迷惘」

- **画面**：照片突然全部飞离抽屉，浮在半空缓慢自转。他伸手去抓，指尖碰到的那一张——是**空白的纸**。
- **镜头**：跟着手 `tilt up`，从抽屉升到半空，照片从画面上方飘出（层片按 z 深度不同速度）。
- **表演**：`confused`；抓住空白纸的瞬间 `surprised`（`take` 1.3，反应最大的一次）。
- **卡点**：17.18 照片起飞（一拍一张，共 5 张）；19.10「惘」空白纸的边缘开始变黑卷曲（0.4s 烧完）。
- **出**：烧穿的洞**用 iris 变焦成下一个镜头的窗洞**（洞形匹配剪辑）。

### 镜 07 · 19.50–24.40 ·「你曾是我心中唯一的信仰」

## 8. 每拍事件规则（保证 65 拍没有空拍）

纸雕风格的"事件"不是每个拍都换镜头，而是**每拍都有一个可见的变化**。按下面四层叠：

| 层 | 频率 | 内容 |
|---|---|---|
| 光 | **每一拍** | 光源亮度 ±6%（`flicker`），前层先动、后层 0.05s 跟随 |
| 纸 | **每一拍** | 画面里至少一张纸片有位移/旋转/展开的一小步（衣物、照片、纸点、纸带轮流） |
| 镜头 | **每一小节**（B1–B17，17 次） | 推 / 拉 / 摇 / 切，见 §6 |
| 大时刻 | 4 次 | 切纸（6.40）、抽层（27.50）、风起（42.96）、影子重合（55.36） |

**硬约束**：
- 相邻两拍不许出现"完全相同的两帧"（除镜 04 的静止段，那段靠光在动）；
- 每小节头上必须有可见变化（换镜或镜头位移 ≥ 4%）；
- 硬动作（刀落、抽层、雨打、影子触）必须落在 §1.3 的词上，误差 ≤ 0.05s。

## 10. 字幕规范

- **位置**：1080×1920 竖屏，水平居中，**距底 260px**（避开抖音 UI）；最长 11 字（镜 01）时宽度 924px，两侧各留 78px。
- **字体**：Noto Serif SC / 思源宋体 Medium，**84px**，字距 +1，暖白 `#F6E6D2`，柔阴影（`0 2 8 rgba(0,0,0,.55)`），透明度 96%。
- **上屏**：每句比开唱**早 0.15s 淡入**（80ms），比句尾晚 0.1s 淡出；两句连播（镜 11/12「但回忆」）第二句不重新淡入，直接文本替换。
- **时间**：严格用 §1.2 的表，不重新对轴。
- **不许**：字幕挡脸（镜 20 特写时字幕降到 200px）、加描边、加逐字卡拉 OK（这支不是 KTV）。
- **画面里出现的字**（照片、纸条）不算字幕，而且本片刻意**不让字看清**——纸条永远是空白。
