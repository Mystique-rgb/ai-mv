## 0. 为什么是油画厚涂

这首歌最难的一件事：**"可不可以"是一句求人的话，但整首歌他一个人都没求到。**

孔版印刷版把这件事做成了"少印一版"；赛璐璐版做成了"隔着 20 米没迈步"。这一版换一个更物理的答案：

**颜料是有保质期的，画不上去，就是画不上去。**

油画厚涂这个画风的媒材本身就在说这件事——
- 颜料是**实物**：一刀一条脊，会堆、会厚、会干、会起皮、会掉渣；
- 颜色是**可以被刮掉的**：刮刀往回一推，昨天的颜色就没了，露出底料；
- 画布是**有限的**：一块地方反复刷，颜料会堆到刷不动。

所以他这三年的动作只有一个：**把这条街重新刷一遍，刷回她还在的时候。**
他成功了 99%。剩下那 1% 是她站过的那一格——它一直是灰的，像画布没上过色。

**这个画风白送的三件事：**

1. **一刀 = 一个鼓点**。全片 820 个底鼓，820 刀。刀落有声音、有高光、有颜料被挤出的边——不需要额外找动效，刀就是节拍器。
2. **"差一点"看得见**。两刀之间永远有一道底料的缝。人和人的距离不需要演，**刀与刀之间那 1–2px 的灰就是距离**。
3. **"过期"有物理形态**。一罐开了三年的颜料，开盖是一圈干壳；刮刀推过去，粉不上，只刮出一道亮痕。**最后那一刀不是煽情，是物理。**

## 1. 一句话

**他把整座城市重新刷了一遍，只为了把颜色刷回她还站在这里的那一天；刷到最后，全城都是新的，只有她站过的那一格，颜料推上去就滑下来。**

不是"他回城里找她"，是**他在做一件注定失败的手工活**。
城市是他的画布，三年是他刷过的层数，保质期是罐底那行印着的日期。

## 2. 画风卡（硬约束，违反任意一条就不是这个画风）

来源：`styles/impasto/STYLE.md`。借画法，不借它的故事、构图、道具。

### 2.1 五条材质纪律

| # | 纪律 | 违反的后果 |
|---|---|---|
| **M1** | **每一笔都是实物**：`KNIFE` 刀痕 = 斜切平面 + 刀口脊 + 起刀唇 + 断色拉丝。不许用"滤镜感"的糊 | 变成"矢量图加水彩贴图"，一眼假 |
| **M2** | **先明度，后肌理**。每个场景先按 3 个明度层做平面设计，读得懂再转刀痕。480px 缩略图读不懂，再多刀也救不回来 | 满屏碎笔，缩略图像噪点 |
| **M3** | **刀痕不跨形体**。人和景是不同的 `group`，轮廓永远硬；只有明确要"失边"时才把两个形体并进同一 group | 人从墙里长出来 |
| **M4** | **底色永远垫一层薄底（underpainting ≈ 1.5px 模糊的原图）** | 刀痕之间露出画布，全场描边 |
| **M5** | **不许颗粒、不许压缩糊**。2× 超采样，高码率，`-crf 16` | 刀口被吃掉，全片像糊了一层油 |

**固定种子**：所有刀痕 `seed` 由 `(镜号, 对象id, 序号)` 算出，**同一物体每帧重画但刀不沸腾**。禁止 `Math.random()`、`Date`、上一帧状态。

### 2.2 色逻辑：全片只有一支颜料是纯的

城市是"混合过的脏色"，他刷的每一刀都掺了一点灰。**只有她的粉是满纯度的**——因为那是唯一一支他单独买、单独用的颜料，开了三年。

| 色 | 值 | 只负责 | 纪律 |
|---|---|---|---|
| **底料灰** | `#9A958C` | 没上色的画布／**那块画不上的地方** | 全片出现频率最高的"颜色"，也是最不颜色的地方 |
| **暖黑** | `#1E1A18` | 夜／影／画布外的黑 | 不是中性黑，永远偏红 |
| **湿石** | `#3B3F46` | 雨里的路面、墙、天桥 | 反射钠橙时不许超过 30% 面积 |
| **冷蓝** | `#2E3F4E` | 窗、远处楼、雨雾 | 只做"远处的冷"，不做主光 |
| **钠橙** | `#C9762F` | 路灯光池、关东煮、招牌 | 全片唯一"暖"的来源 |
| **窗金** | `#E8B25C` | 亮着的窗、灯丝、热气 | 副歌里的金句字用它 |
| **他（赭土）** | `#8A6A3E` / 暗 `#4A3A28` | 阿岩的工作服、围裙、手 | 身上不许出现纯色 |
| **她（粉）** | `#E0708C` | **只有她的痕迹** | **全片唯一满纯度的色。别人身上永远不许有粉** |
| **干粉** | `#B98F98` | 粉干到某个阶段后的样子 | 与 `#E0708C` 之间用**五级递减**（见 §5③） |
| **钛白** | `#F4EDDF` | 最亮的那一刀、刻出来的字幕 | 白是"刮出来的"，不是"打光打出来的" |

**两条铁律：**
1. **粉只出现在她站过的地方**——长椅右半、玻璃门上的手印、斑马线的一道影、便利店杯垫、方砖的一个圈。**画面上出现粉，就说明"她在这里待过"，不是"她在这里"。**
2. **她本人只在 5 个镜头里"实体在场"**，而且**全部是回忆**，且一次比一次薄（见 §5③）。现在时空里她**一次都不出现**。

### 2.4 人物：从资产库 human 到"刀痕人"

> 资产库 human 是"有描边平涂"。厚涂**没有描边**——形是刀痕的边界，脸是几刀淡色叠出来的。骨架、比例、情绪系统全部照旧，只改写"怎么落刀"。

| 部位 | 资产库原样 | 本片做法 |
|---|---|---|
| **轮廓** | 2–3px 墨线 | **不画线**。用一圈**短、窄、压暗的刀**（比身体色暗 20%）沿边缘排，边界靠明度差咬住 |
| **身体** | 单色平涂 | **3 刀**：亮面一刀（`#8A6A3E`）、暗面一刀（`#4A3A28`）、过渡一刀（两色拉丝，`c2` 掺入） |
| **脸** | 肤色平涂 + 五官 | **4 刀**：颊（暖白 `#E3C49B`）、阴影侧（混 vio `#9A8570`）、下巴（一条 3px 短刀）、额头（起刀唇朝上）。**脸是全片刀最小的区域**（`detail` 最高） |
| **眼** | 椭圆 + 高光 | **两刀深色 + 一刀白**。瞳孔 = 一小块几乎不透明的暗色刀；高光 = 一滴 `DAB`，白里掺 10% 钠橙 |
| **嘴** | 线 | 一刀短横（`KNIFE`，长 0.9u，宽 0.15u），嘴角用两滴 `DAB` |
| **头发** | 平涂 + 描边 | **5–7 刀**沿发流方向向后拖，起刀处厚、收刀处断（断口就是发丝） |
| **手** | 纸白块 | 3 刀：掌一刀、指一刀（方向朝用力方向）、指缝用**底料缝**（不画线，留 1px 灰） |
| **湿/雨** | — | 身上的雨 = **白色短刀点**，只在迎光侧，每拍掉 1–2 滴 |
| **尺寸** | 3 头身 | 与资产库一致。1080p 中景身高 ≈ 420px，特写脸 ≈ 300px（此时单刀宽 ≤ 7px） |

**两条动作约束：**
- 人物身体走 **12fps（on twos）**，姿势用整块 squash/stretch + 倾斜，不做关节动画；
- **刀痕、光、雨、车流走 24fps（on ones）**。人比颜料慢——这个不同频就是厚涂的节奏感来源。

### 2.5 表情系统（每拍换一次，8fps 换版）

| 名 | 眼 | 嘴 | 用在哪 |
|---|---|---|---|
| `calm` | 两刀深 + 一滴小高光 | 短横 | 默认 |
| `blink` | 一刀横压（整张闭） | 短横 | 每 3–4 拍一次，不然像标本 |
| `soft` | 上眼睑下压 25%，高光偏内 | 极轻微上弧 | 回忆段 / 看她待过的地方 |
| `hurt` | 眼下垂，高光缩小、位置下移 | 下撇 2px | 主歌一、副歌二 |
| `grit` | 眼缝压到 40%，高光被压成一条 | 牙关（短横加粗） | 下决定、推最后一刀 |
| `wide` | 眼放大 1.3，高光跳一格 | 小圆 | 认出、被灯照到 |
| `smile` | 弯成两道（用刀背弧） | 上弧 + 颊肌两滴 `DAB` | 快句段、回忆 |
| `empty` | **无高光**（只剩两刀暗） | 短横 | **只允许结局最后 3 镜用** |

**硬规则**：每个有人的镜头，**每一拍至少换一次版**；同一表情**连用不超过 2 拍**；`empty` 全片 ≤ 3 镜。

### 2.6 字幕：字是刻出来的（不是叠加 UI）

厚涂不能"写字"——颜料上写不了小字。所以字幕换了一个物理动作：**用刀把颜料刮穿，露出底下的米白底料。**

- **普通句**：一道一道的白色刮痕组成字（负形）。字宽 ≈ 48px（中文），行距 1.0，**底部往上 88px，居中**，不挡脸。
- **上屏**：**一刀一字**，每字 0.06s，从左到右。整句 ≤ 0.5s 刮完，永远不"淡入"。
- **下屏**：被下一刀颜料**盖住**（`appear` 扫过），或一秒内被雨冲掉——不淡出。
- **金句**（line24 / 25 / 36 / 37 / 44 / 45 / 46 / 47）：**刻穿到底**（刮到画布，边缘起毛、有撕口），字边一圈干粉 `#B98F98`。
- **字跟着画面动**：镜头推，字也推；刀落时字抖 1px。

### 2.7 节奏分层

| 元素 | 帧率 | 说明 |
|---|---|---|
| 刀痕 / 光 / 雨 / 车流 / 灯 | **24fps** | `on ones`，一帧一刀，绝不插值 |
| 人物姿势 | **12fps** | `on twos` |
| 表情（眼/嘴/高光） | **8fps** | `on threes` |
| 字幕 | **24fps** | 逐字刮出 |

- **移动光，不移动画**：灯池、车灯、雨幕在**静止的刀痕**上扫过（`source-atop`），比让整个画面动便宜且高级。
- **冲击帧**：2 帧反相（底料白 / 暖黑）+ 刀口白光 + 放射干笔，然后接结果。
- 硬切切在小节头；转场只用：**硬切、颜料覆盖扫（paint-over）、刮除（scrape）、冲击帧**。**不许溶解、不许划像**（两层刀痕叠一起就是泥）。

### 2.8 镜头语法

| 运镜 | 表达 | 用在哪 |
|---|---|---|
| 慢推 + 横移（3 层视差） | 观察一个地方 | 开场、空镜、城市空转 |
| 穿过一段静默推进 | 内在压力 | 决定、放弃、说"可不可以" |
| 从地面或倒影上摇 | 从低处发现 | 他出场、第一次看见痕迹 |
| 特写拉远 | 世界的回答 | 每次他抬头 |
| 旋转升起 + 俯拍 | 多数里长出图案 | 车流、人群、全城 |
| 同一构图重画 | 前后对比 | **三次副歌** |
| 锁定机位，光在动 | 时间与天气是演员 | 间奏、雨停 |
| 沿颜料表面微距滑移 | 讲媒材本身 | 开场第一刀、罐底日期 |
| 甩镜进另一块画板 | 能量、跳跃 | 快句蒙太奇、副歌三 |
| 极特写眼睛 | 决心／认出 | 副歌三、结局 |

**构图纪律**：镜头永远待在画板内（`half = W/2/zoom`），不许露画布边。主体拿硬边和最小刀；其余地方留大片安静的平面。

### 3.3 纪律

- 阿岩的色 = **赭土 + 手上的颜料**；小粉的色 = **粉**；这两个色任何景物都不许用。
- 城市里所有"红"只能是**塑料红 `#B8402F`**（比粉脏、比粉暗）。
- 群演不许有脸；有脸的都是有名有姓的人。
- **凡是出现在画面里的粉，必须能追溯到"她曾待过"的某个具体位置**。追不到就删掉。

## 4. 世界观：一座城 = 一面墙 = 三年

### 4.1 五个场地（一套色模型对应一个）

| # | 场地 | 用在哪 | 板上必须有的东西 |

### 4.2 光的曲线（一条向下的线，最后反弹一次）

**雨夜（`N-RAIN`）→ 钠灯最亮（`N-SHOP`）→ 雨停（`N-RAIN`）→ 笔干（`N-DRY`）→ 黎明（`DAWN`）**

### 4.3 城市作为第二演员的三条规则

1. **城市在替他干活**：他刷一块，城市自己亮一块；他停下，城市继续（灯一盏盏亮、卷帘门一扇扇落）。**他不在的镜头，城市也必须有事件**（间奏 28 秒全靠这个撑）。
2. **城市记得她**：所有粉的痕迹都在"她待过的高度"——坐姿 0.45m、手印 1.1m、影子贴地 0.02m。**粉从不出现在她够不到的地方。**
3. **城市不等人**：小豆的电驴、过街的人、落下的卷帘门，永远比阿岩快半步切过画面，**切的位置正好在他和她之间**。

## 5. 三条硬主线（改稿不许破坏）

### ① 灰斑：那块画不上的地方

- **位置固定**：P1 街角招牌墙脚下，**第三块方砖**，画面坐标永远在右下 1/3（近景时在画面下方 62% 高度，俯拍时在城市网格的第 7 街 × 第 3 巷）。
- **它不是一个特效，是一个"没有颜料的洞"**：底料灰 `#9A958C`，边缘有一圈被刀推过的堆积（颜料在边界堆高、发亮），中间永远是平的灰。
- **尺寸曲线**：S01 一条缝（2px）→ 主歌一 一块砖（120px）→ 副歌一 一块砖（不变，因为他绕开了它）→ 桥段 掀开一半（她能站的地方）→ 副歌二三 **一个人宽**→ 结局 一整格（180×180px），**刀推过去也上不去**。
- **规则**：**全片任何镜头，只要 P1 在画面里，灰斑就必须在画面里**。它跟着摄影机走，不跟着他的注意力走。

### ② 三次副歌 = 同一幅画重刷三次

同一机位、同一构图、同一面墙（P1 全墙），**三次副歌各刷一遍**，每次都只有"颜料的状态"变了：

| | 段落 | 颜料 | 画面结果 | 灰斑 | 他 |
|---|---|---|---|---|---|
| **第 1 遍** | 副歌一 bar40.2–56（71.44–101.31） | **新开的、湿润的** | 满彩。刀痕脊上的光在跳，颜色饱和到有点脏 | 一块砖 | 兴奋、快，动作大 |
| **第 2 遍** | 副歌二 bar88.2–101.2（156.72–179.52） | **半干**：拖毛、掉渣、刀拉不动 | 只有一半色，另一半是刮痕和底料。同一条刀痕在中途断成两截 | **一个人宽** | 慢下来，开始用两只手推 |
| **第 3 遍** | 副歌三 bar101.2–116.1（179.52–206.56） | **枯笔**：罐里没了 | 几乎没有色，只有刀在墙上划出的亮痕和底料。像一张被擦过的画 | **一个人宽，且刀在上面打滑** | 用力、狼狈、最后一刀跪着推 |

> **判定方式**：三次副歌的**第 1 拍画面必须能叠上**（同机位同构图，只有颜料状态不同）。做不出来就不算这一版。

### ③ 粉的五次递减

他的那支粉，每一次出现都比上一次少一个色阶——因为罐里的粉在干。

| 次 | 位置 | 饱和度 | 形态 | 剧情 |
|---|---|---|---|---|

| **2** | S25 / S26 · 长椅右半 + 空位 | **75%** `#D4788E` | 一块坐出来的粉，边缘开始发白 | 副歌一：他还画得动 |

### 6.3 三条硬规则

1. **一拍至少一件，重鼓叠第二件。** 521 拍 / 820 底鼓 = 平均 1.57 个底鼓/拍，所以**有一半的拍要放两件**。
2. **有人的镜头，每拍必须换表情。** 全片有人的镜头约 44 个，覆盖约 340 拍 → 340 次表情切换，这是"高能"的底噪。
3. **"大时刻"必须是画面本身变，不是加特效。** 变化 = 颜料状态、光的模型、画面尺度、世界翻转。闪白、震屏只是调料，全片允许 **5 次**（M1–M5）。
