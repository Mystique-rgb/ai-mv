# 《可不可以》MV 分镜提示词 · v1
## 画风：80 年代赛璐璐动画（city pop）· 系列《返航之夜》· 阿岩 × 小粉 · 全程高能

- 曲目：张紫豪《可不可以》 240.89s / **BPM 134.98** / 拍 0.4446s / 小节 1.7782s / **130 小节 / 521 拍 / 820 个底鼓**
- 拆解来源：`mv2-listen/song.json`（`listen.py` 实测，伴奏轨 `no_vocals.wav` 找拍，和起音偏差 6ms）
- 歌词：47 句，**逐字时间是强制对齐**（Qwen3-ForcedAligner，约 80ms 精度），不是 LRC 估的
- 画风：lemo-opuscar `styles/cel-anime-80s/`（四层结构：手绘背景板 + 平涂赛璐璐 + 逆光 + 磁带 CRT）
- 人物：Clawd 人物资产库 v2 human 模式 —— 男主 **阿岩**（`a`）、女主 **小粉**（`b`）、配角 **老周**（`zhou`）、**小豆**（`dou`）
- 规格：1920×1080 / **24fps** / 人物动作 **12fps 步进（on twos）** / 表演节拍 **8fps（on threes）** / 镜头·光·雨 **24fps（on ones）**
- 结局：**开放式 —— 她回头，不给答案**

## 1. 一句话

**他在一夜里走回一座城市，城市把三年的记忆一件件砸在他身上，最后只还给他一条街的距离。**

他当年说好带她去流浪，半路一个人回来了。今晚他回来了——不是回这座城市，是回**这一条街**。城市比人走得快：车、扶梯、霓虹、雨，全都比他快。只有一处为他停下来：天桥。

**三个红利**（不是妥协，是这个画风白送的）：

1. **赛璐璐天生两张脸**：平涂的 cel 是"现在"，逆光剪影是"记忆"。同一套头，换一套色指定就是另一个人生阶段——三年的回忆不需要换画风，只需要换一套色模型。
2. **磁带就是回忆的物理形态**：80s 动画自带录像带质感。所以回忆不用淡入淡出，用 **tracking 撕裂 + 色偏** 塞进去——像把一盘带子推进机器。间奏 30 秒的"倒带"因此是合法的，不是花招。
3. **城市会替他说话**：玻璃、水洼、车窗、电视墙、电梯镜面——80s 城市的表面全是反光。他一句话不说，城市替他说。

## 2. 画风卡（硬约束，不许改）

> 从 `styles/cel-anime-80s/STYLE.md` 抄成施工条款。违反任意一条，画面立刻从"80s OVA"掉成"现代数字动画"。

### 2.1 四层，缺一层就不是这个画风

| 层 | 做法 | 本片用在哪 |
|---|---|---|
| **① 手绘背景板** | 开机时画一次：柔和喷枪渐变、发光的窗、湿地反光；再存一张**发光副板（emissive plate）**，两张一起平移 | 站前街、食街、天台、天桥——每处一套板 |
| **② 赛璐璐 cel** | 平涂 + **硬边**阴影月牙 + **硬边**高光月牙 + **彩色**轮廓线（**永不用纯黑**） | 阿岩、小粉、老周、小豆、车、伞、关东煮 |
| **③ 逆光（透過光）** | 招牌、路灯、字幕、霓虹**穿过**画面发光；光斑、光晕（halation） | 全片夜景；副歌三连加倍 |
| **④ 磁带 + CRT** | 色度溢出、扫描线、RGB 栅格、荧光拖影、四角压暗、细噪点 | 全片，字幕在这一层里合成 |

**判据**：一帧如果看起来像"现代数字动画"，一定是少了某一层。本片最常见的掉层是 ③——cel 上没有那道饱和霓虹**轮廓光（rim light 2–4px）**。

### 2.2 人物画法（80s way）

- 头：长蛋形，下颌柔、下巴尖；3/4 侧面远眼要**透视压缩**，颧骨有一个转折面。
- 眼：**杏仁形**，位置在头部垂直中线附近（不是萌系的大眼低置）；粗上睫毛线，向外挑；竖椭圆虹膜 + **两个高光**；眉毛长而细。
- 鼻：一块阴影面 + 一笔；腮红只有一层很淡的（**不许排线**）。
- 头发：重叠发绺 + 尖锐不齐的发梢，压在一层更宽的深色底层上；一条连续的**"天使环"高光**，下缘是锯齿。
- 线：皮肤用暖深棕细线，头发用深紫，只有**硬道具**接近黑。
- 情绪只在五处：眉毛、眼皮高度、虹膜大小、嘴角、肩膀。

**本片的取巧**：STYLE.md 明确说"正面最难画"。所以——

> **阿岩的正脸只给 6 次**：S12 冲出地铁门、S24 笑、S59 特写、S65 抬手、S66 她转过来那一刻的**不对视**、S67 结尾。其余全部 3/4、侧脸、背影、逆光剪影、玻璃倒影。
> 小粉在 S41–S55（白天回忆）可以给正面；在夜景里她**始终是侧脸、背影、倒影、或 3px 的粉色块**——因为她已经"不在原地"了。

### 2.4 材质与光（施工）

- **自动月牙阴影**：裁切到形状里，用 `shape − shape 沿光向平移` 填阴影色（奇偶规则）；反向平移填高光；再反向平移 2–4px 填**饱和霓虹轮廓光**。每套光单独一套（见 2.3）。
- **背景板湿地面**：把发光板**翻转 + 模糊 + 拉竖条**再压暗，加波纹带；水洼反光**每拍横向位移 2–6px**（G10）。
- **发光**：从 emissive 板强泛光，彩色板上只对 >0.9 的部分弱泛光；最宽那层泛光染红橙（halation）。**每个 cel 的轮廓都要用黑色盖进 emissive 板**——不然霓虹会从人物身上透出来。
- **招牌字**：只写通用词（「旅馆」「食堂」「电玩」「雨伞」「理发」「冷饮」「夜宵」），**绝不出现真实品牌**。
- **磁带后期**（确定性，不用随机）：色度溢出（亮度锐、色度横向糊 2px 并偏移）、扫描线（按输出像素固定，亮处缝隙变窄）、RGB 栅格、荧光拖影、四角压暗（不做圆角）、细信号噪点。

### 2.5 节奏（这条决定"高能"是不是真的）

| 元素 | 帧率 | 说明 |
|---|---|---|
| 人物身体/姿势 | **12fps**（每 2 帧换一张，on twos） | 换姿势、换腿、换手，都在 12fps 网格上 |
| 表演（眨眼、睁眼、口型、表情切换） | **8fps**（每 3 帧，on threes） | 表情是"三张一换"，不是连续插值 |
| 镜头、光带、泛光、雨、车流 | **24fps**（on ones） | 镜头一旦步进就会出现"抖动"，禁止 |

- **发/衣 = 带状 ribbon**：由一条行波正弦驱动，4 张循环（平静时 6 张）。
- **"移动光，不移动画"**：彩色光带在**静止的 cel** 上扫过（`source-atop`）。
- **冲击帧**：2 帧反相/单色剪影 + 放射线，然后接结果。
- **守住峰值**：可以有一张"一张画停住 + 慢摇"的 harmony 静帧——全片允许 **3 处**（S09 水下、S39 线稿静、S67 结尾）。
- 硬切**切在小节头**；转场只用：硬切、闪白、冲击帧、磁带撕裂。**不许数字溶解、不许划像。**

### 2.6 镜头语法（表，不是路线）

| 运镜 | 表达 | 本片用在哪 |
|---|---|---|
| 多层横移（3–4 层视差） | 稳定的推进感 | 沿街走、跑、食街全景 |
| 高板摇臂升降 | 世界一层层揭开 | 站前广场、天桥俯瞰 |
| 背影进伪 3D 峡谷 | 速度、前方有压迫 | 扶梯、地下通道、天桥阶梯 |
| 停住的半身 + 光带扫过 | 有速度感但不画动画 | 地铁抓吊环、等灯 |
| 插入镜 + 散景 + 滑动高光 | 这个物件重要 | 红发圈、车票、保质期标签 |
| 眼极特写 | 决心、认出 | S59、S66 |
| 慢摇过一张静帧 | 屏息、记忆 | S09、S39 |
| 放射速度线 + 一拍冻结 | 撞击前的一瞬 | 副歌起跳、冲门 |
| 穿窗/穿屏推进 | 进另一个世界 | 进回忆（S41）、电视墙（S30/S52） |
| 锁定双人 + 口型 | 对话 | **本片不用**（他全程不说话） |
| 同一构图重画 | 什么变了 | 三次副歌（见 §5 硬主线 2） |

### 3.3 纪律

- 阿岩的 accent 色 = **红发圈**；小粉的 accent 色 = **白球鞋**（夜里反光的两片白）。这两个色任何景物都不许用。

## 4. 世界观：一座城 = 一条街 = 三年

### 4.1 四个场地（一套板一个场地，不许混）

| # | 场地 | 用在哪 | 板上必须有的东西 |
|---|---|---|---|
| ① | **站前街** | 开场 / 返航 / 决定回去 | 长途车站闸口（4 道）、大钟（21:47 起）、出租车流、地铁口扶梯、湿到能照人的地砖 |
| ② | **食街** | 我可以…（S17–S24） | 一条 60m 长的遮雨棚，两侧招牌 22 块、关东煮车、扭蛋机、棉花糖机、塑料凳 |
| ③ | **天台** | 三年前（S41–S44、S47） | 晒衣绳 6 条、水泥水塔、铁丝网、隔壁楼的一整面马赛克瓷砖墙 |
| ④ | **天桥** | 副歌二/三 / 结尾 | 跨 6 车道，两侧广告灯箱 12 个，桥面雨积水，尽头一段没灯 |

### 4.2 时间与光（全片 7 小时 30 分，一条向下的曲线）

`21:47` 站前（N-RAIN）→ `23:10` 食街（N-SODIUM）→ `01:20` 空城 / 倒带（N-RAIN 减饱和）→ `三年前 14:00`（D-HAZE）→ `04:50` 天桥（PRE-DAWN）→ `05:12` 一线金

### 4.3 城市作为第二演员的三条规则

1. **城市永远比人快**：车流、扶梯、霓虹循环、群演，一律比阿岩的步子快一档。他越急，城市越快。
2. **城市替他说真话**：他全程不说一句话。小粉的脸只出现在**表面**上——玻璃、水洼、车窗、电视墙、电梯镜面。他一转头，表面就只剩雨。
3. **城市只在一处停下**：从 **bar122** 起，所有动态元素速度降到 **0.25×**，只有雨还在正常下——因为雨是天的，不归城市管。

## 5. 三条硬主线（改稿不许破坏）

### ① 红发圈：口袋 → 手心 → 指上 → 举起 → 留下

| 次 | 位置 | 时间 | 状态 |
|---|---|---|---|
| 1 | 口袋露一角 | S06 · bar7 | 只看得见 3px 的红 |
| 2 | 天台地上 | S43 · bar77 | 落在地上，他在捡 |
| 3 | 套在食指 | S48 · bar87 | 副歌二起手，像戒指又不是戒指 |
| 4 | 掏出、套上 | S62 · bar114 | 正面、两只手、8fps 三张 |
| 5 | 举起来 | S65 · bar119 | 对着 20 米外的她 |

> 第五次之后**不再出现**。如果她走了，发圈留在栏杆上；她回头，发圈还在他手上——**这个不确定就是结局**。

### ② 三次副歌 = 同一组镜头，三次重印

| | 段 | 机位 | 变了什么 |
|---|---|---|---|
| **一** | bar40–56（71s） | 基准版（S26–S33） | 城市亮的，人是空的 |
| **二** | bar87–103（156s） | **机位/构图一个不动**（S48–S55） | 每个镜头里多一样东西：手上多了发圈 / 招牌窗里是她在看他 / 她的背影出现在长椅上 |
| **三** | bar101–121（179s） | 换到天桥，**同一套构图的远景版**（S56–S65） | 城市开始失速，人满了 |

**纪律**：第二遍的每一镜必须能和第一遍**叠帧对齐**（同焦距、同水平线、同人物站位）。观众说不出哪里不对，但会觉得"这片子在原地打转"——这正是歌词在干的事。

### ③ 城市失速

- bar0–100：城市速度 **1.0×**
- bar101–116：**0.6×**（车流变慢，招牌闪得变慢，群演停下）
- bar117–121：**0.25×**
- bar122–130：**0**（只有雨和呼吸）

## 6. "全程高能"怎么落地

### 6.1 十二个事件发生器（每个鼓点都有事，不靠手写 820 条）

| 号 | 发生器 | 触发 | 具体动作 |
|---|---|---|---|
| G1 | **光带扫过** | 每小节头 | 一道 60px 宽的彩色光带横穿画面（`source-atop`），0.3s |
| G2 | **8fps 换版** | 每拍 | 表情/姿势在三张画里换一张（眨眼、转头、换腿、手指动） |
| G3 | **冲击帧** | 重鼓 | 2 帧反相或单色剪影 + 放射线，然后接结果 |
| G4 | **招牌呼吸** | 每拍 | 霓虹亮度 ±18%，偶尔换一个字（「旅馆」→「旅」） |
| G5 | **雨/水花/蒸汽** | 每拍 | 3–8 个粒子，24fps，落点必在画面下部 1/3 |
| G6 | **机位 judder** | 重鼓 | 3–5px 位移，0.12s 衰减，不回弹过冲 |
| G7 | **色版跳** | 段落 / 大时刻 | 整套色指定在 8 帧内切过去，chroma bleed 拖 0.8s |
| G8 | **磁带撕裂** | 进/出回忆 | 2–4 帧 tracking 噪声 + 纵向跳行 |

### 6.3 三条硬规则

1. **一拍至少一件，重鼓叠第二件。** 521 拍 / 820 底鼓 = 平均 1.57 个底鼓/拍，所以"一拍一件"是最低标准，不是目标。

## 8. 字幕

- **位置**：底部往上 96px，居中。**不挡脸**（所有正脸镜头都留了下部空间）。
- **字**：Barlow Semi Condensed 600 的等价中文字重（思源黑体 Medium 替代），**72px**，奶油黄 `#F7E9C4`，描边 4px 深褐 `#3A2A22`，柔阴影 6px。
- **合成层**：字幕在**磁带层之内**（跟画面一起吃扫描线和色度溢出）——它是"录像带上本来就有的字"，不是贴在视频上的 UI。
- **时序**：逐字时间来自 `song.json`。淡入在开唱前 **0.10s**，唱完 +0.25s 淡出。换句时前一句立即让位，不叠加。
- **长句**：一句一行，**不折行**。最长「只是刚好情窦初开遇到你」11 字 × 72px ≈ 792px，安全。
- ⚠ **最后一处待定**：`line47「趁你还愿意」` 强制对齐是 **220.96–221.68（0.72s）**，但 LRC 给的是 220.97–227.69（6.7s），音乐里这句确实拖了长音。**建议**：字在 221.0 全部上屏，**保持到 227.6 再淡出**（跟 LRC 的长音走）。这一条需要你点头。

## 9. 技术实现（给写代码的人）

```
可不可以/
├── mv2-listen/          song.json / song.md / songmap.png / audio.wav（只读，别改）
├── scene/               index.html / scene.js / cues.json / plan.md
├── style/               cel.js  pal.js  head80.js  hands.js  bg.js  fx.js  post.js  （从 cel-anime-80s/demo 借技法，重写内容）
└── out/                 stills/  mv_草稿.mp4  mv.mp4
```

| 要做的事 | 怎么落 |
|---|---|
| 人物 12fps | `step = Math.floor(t*12)/12` 后取姿势；表演层再 `Math.floor(t*8)/8`。**姿势切换不许插值** |
| 镜头 24fps 平滑 | 运镜函数直接吃 `t`，不要 step |
| 五套色模型 | `pal.js` 里五组常量，`#5` 号槽 `RED = #E23A2E` 不参与乘色 |
| 背景板 | 每个场地开机画一次（colour + emissive 两张），之后只平移；湿地面 = 翻转模糊拉条 |
| 光带 | `source-atop` 裁到 cel 形状里，宽 60px，每小节头触发 |
| 冲击帧 | 2 帧反相或单色剪影 + 放射线，`t` 落在重鼓上 |
| 倒带段 | `G8` = 2–4 帧 tracking 噪声 + 纵向跳行；色偏往青绿，整段常驻 |
| 后期 | WebGL 一遍过：泛光 → 调色 → 色度溢出 → 扫描线 → RGB 栅格 → 四角压暗 → 噪点 → 字幕 |
| 确定性 | 所有随机用 `M.hash(i)` / `M.rng(seed)`，**禁止 `Math.random()` 和 `Date`** |
| 字体 | `document.fonts.load` 每个字重，加载完再画（canvas 会静默回落成衬线体） |

**校验**：写完 `cues.json` 先跑 `python -I scripts/cue_lint.py`，0 个 ✗ 才画。

## 11. 待你点头的 6 件事

1. **字幕 72px** —— 风格库建议 50–56px（磁带质感），但手机竖屏看偏小。取 72px 折中，要不要再大？
2. **小粉在夜景里不给正脸** —— 只有白天（S42–S48）和 S52 那 0.2 秒。这是"她不在原地"的技术手段，但观众可能会觉得"女主戏太少"。
3. **老周 / 小豆 要不要留** —— 现在各出现 2 次，纯功能。删掉也不影响（只剩 2 个角色，画面会空一点）。
4. **画幅** —— 现在按 16:9 全画幅。风格库说 4:3 加黑边（pillary）也是合法的 OVA 感，更有年代味，但手机上损失两侧。
5. **间奏 30 秒倒带** —— 全片最实验的一段（雨倒飞、车倒开、线稿上色）。要不要收敛成 15 秒？
6. **结尾伞落在栏杆上** —— 现在两人在最后一镜都出画了，只剩伞。要不要保留"她在画面里"到最后一帧？
