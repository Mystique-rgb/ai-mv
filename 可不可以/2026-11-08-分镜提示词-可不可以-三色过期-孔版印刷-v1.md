# 《可不可以》MV 分镜提示词 · 孔版印刷版 v1
## 画风：Risograph 孔版印刷 · 系列《三色过期》· 三版一纸 · 全程高能

- 曲目：张紫豪《可不可以》 240.89s
- **速度 134.98 BPM**／一拍 **0.4446s**／一小节 1.7782s／**130 小节 / 521 拍 / 820 底鼓**
- 歌词 **47 句**，逐字强制对齐（约 80ms）
- 画风：lemo-opuscar `styles/risograph/`（三专色 + 暖白纸 + 网点 + 套版错位）
- 人物：Clawd 资产库 v2 human —— 阿岩 `a`、小粉 `b`、老周 `zhou`、小豆 `dou`
- 规格：1920×1080 / **24fps 渲染**
- 帧量化：一拍 = 10.67 帧，不整除。**所有事件按 `song.json` 的拍时间换算成帧，允许 ±1 帧量化（≤21ms）**；人物动作走 12fps（on twos），印刷事件走 24fps（on ones）
- 字幕：47 句全上，**普通句印蓝版、金句蓝+粉双版套印错位 3px**
- 结局：**空白纸上一颗 1px 粉点**

> 与 v1 / v2（80s 赛璐璐·返航之夜）**没有任何继承关系**：画风、故事装置、角色画法全换。只共用同一份音乐拆解与同一套人物。

## 1. 一句话

**他把同一个夜晚印了三次，每次都差两毫米；等他对齐了，纸上她已经薄得透光。**

不是"他回城里找她"，是**他在调一块永远调不准的版**。三年是他用的纸，回忆是油墨，保质期是油墨干掉的日期。

**"孔版印刷"白送的三件事：**

1. **颜色是加法，也是减法**——一块版没上，画面就少一个人。她的缺席不需要演，**少印一版就是缺席**。
2. **套不准是常态**——两次印刷不可能严丝合缝。所以"差一点"不需要台词，**两版之间那道 2px 缝就是"差一点"**。
3. **会褪、会干、会过期**——油墨是有保质期的。这首歌最后一句反复问"趁你还愿意"，在这个画风里它有一个物理答案：**再印就印不上了**。

## 2. 画风卡（硬约束，违反任意一条就不是这个画风）

### 2.1 只有三块版、一张纸

| # | 版 | 色值 | 只负责 |
|---|---|---|---|
| **IN-1** | 联邦蓝 | `#3D5588` | 城市／夜／雨／**他** |
| **IN-2** | 荧光粉 | `#FF48B0` | 小粉／回忆／暖／**她** |
| **IN-3** | 向日葵黄 | `#FFB511` | 光／灯／时间／**保质期** |
| — | 纸 | `#F4EEE2` | 没印上＝缺席＝空位 |

**叠印结果（全片只认这四种混合）**

| 组合 | 结果 | 含义 | 允许出现的地方 |
|---|---|---|---|
| 蓝 + 粉 | **紫** `#5A3A6E` | 两个人真的碰到 | 只在人物轮廓重叠处。**紫的面积＝他们的距离** |
| 蓝 + 黄 | 墨绿 `#2E5A46` | 现实（冷柜、末班车、工位） | 场景 |
| 粉 + 黄 | 朱橙 `#E8571F` | 三年前的暖 | 只在前奏/闪回段 |
| 三版全叠 | **墨黑** `#1A1520` | 时间到了 | 局部（头发、印章戳记、金句字幕）随时可用；**整幅画面三版全叠只准 bar80 的两拍** |

> 注意区分：**局部全叠**是这个画风的日常（头发就是三版叠出来的黑），**整幅全叠**是核弹，全片只放一次，就是 bar80 那两拍。这样那一击才有分量。

**三条上墨纪律**

1. **一块区域内最多两块版，其中最多一块是网点（tint）。三块网点叠在一起＝烂泥。**
2. **粉只属于小粉。** 画面里出现任何粉——她的衣服、她的手、她按过的栏杆、她被纸边割出的血——都是"她在"的证据。**别人身上永远不许有粉。**
3. **纸白是颜色，不是空白。** 每帧必须留 ≥25% 的纸白；人物身边必须有 4–5px 的纸白敲白晕圈（knockout halo），版从晕圈外错位进来，边缘才会长出彩色毛边。

### 2.2 人物画法改写（资产库 human → 孔版）

> 资产库的 human 模式是有描边的平涂。孔版印刷**没有描边**——形是色块，脸是敲白。改动如下，骨架和动作全部照旧。

| 部位 | 做法 |
|---|---|
| **轮廓** | **不画线**。整个人的形状＝一块实心版（他＝蓝 100%，她＝粉 100%），形状即轮廓 |
| **脸** | **敲白**：脸是一块纸白的洞（4–5px 晕圈），没有肤色，没有描边 |
| **眼** | 两个墨黑实心竖椭圆（5×8px）。**全片只用三种**：圆点 `open`／弯月 `smile`／一条横线 `close` |
| **嘴** | 一条墨黑横线 `flat`／上弧 `smile`／小圆 `o`／下撇 `sad`。**宽度不超过脸的 1/3** |
| **头发** | 实心墨黑（三版叠）。丸子头/双丸子照资产库位置，但只有剪影 |
| **腮红** | 粉 20% 网点，只在笑和羞的时候出，**不许常驻** |
| **手** | 纸白块 + 2 条墨黑指缝。**接触时才会吃到对方的色** |
| **卫衣细节** | 只保留 2 个：兜帽弧、抽绳。抽绳是一条 2px 墨黑 |
| **尺寸** | 与资产库一致（3 头身），在 1080p 里中景身高 ≈ 420px，特写脸 ≈ 300px |

**孔版特有的两条动作约束**

- 人物在 12fps 上做动作（on twos），但**上墨/错位/网点在 24fps 上跑**——人和印刷不同频，这正是这个画风的节奏感来源。
- 任何"接触"都要在**同一帧**里让两版叠上：先画他的蓝，再画她的粉（`lighter` 叠印），重叠区自动成紫。**紫不许手画，必须算出来。**

### 2.3 表情系统（每拍换一次，12fps 换版）

| 名 | 眼 | 嘴 | 用在哪 |
|---|---|---|---|
| `calm` | 圆点 | flat | 默认 |
| `blink` | 横线（一张） | flat | 每 3–4 拍一次，不然像纸人 |
| `smile` | 弯月 | smile | 她的默认；三年前全片 |
| `wide` | 圆点 ×1.3 | o | 看见她／被抓到 |
| `sad` | 圆点 ×0.8，上眼睑压下来 | sad | 主歌 |
| `grit` | 横线压扁 | flat 加粗 | 决定的那一下 |
| `love` | 弯月加粗 | smile 张嘴 | 副歌满版紫的段落 |

**硬规则**：每个有人的镜头，**每一拍至少换一次版**。521 拍里有人物的约 380 拍，就是 380 次表情切换——这是"全程高能"的底噪。

### 2.4 字幕印法（这不是叠加 UI，这是第四样印刷品）

- 普通句：**纸白敲白条**（零墨，圆角 3px）+ **蓝版单词**，思源黑体 Medium 40px，字距 0.04em
- 金句（line24 / 25 / 44 / 45 / 46 / 47）：**蓝版 + 粉版双色套印，横向错位 3px**——字边自己长出紫。**这是"她也在说这句话"的唯一视觉证据。**
- 字幕随版走：套版踢的时候字一起踢（±3px，0.2s 回弹），滚筒扫过时字被墨盖一半再露出来
- **字幕永不淡入淡出**：印刷没有渐变，只有"印上"和"没印上"。上＝1 帧到位，下＝1 帧消失
- 位置：底部安全区，左对齐 168px（学 city-symphony 的克制，不用居中）

## 3. 三色语法：全片的"距离表"

> 这是本片唯一的情绪量具。**紫的面积曲线就是他们的距离曲线**，而且它能被脚本量化检查（见 §10）。

| 时点 | 紫宽 | 怎么来的 | 观众该感觉到 |
|---|---|---|---|
| bar9（16s）| **1px** | 三年前，她拉他袖口 | 有过 |
| bar11–24 | **0** | 车开走、蓝海淹没、白洞吞手 | 没了 |
| bar28.4（51s）| **0** | 糖从两人手之间滚过，中间有 2px 纸白缝 | **故意不给** |
| bar33（59s）| **4px** | 他的拇指按住她手背的缺墨划痕 | 又能碰到了 |
| bar37（66s）| **2px** | 两只手差 2px，只剩一道紫色细线 | 差一点 |
| bar42–56（副歌一）| **4–8px** | 她扶他肩，隔着衣服 | 隔着 |
| bar80（141.76s）| **满版** | 三版全叠→裂开→紫 | 全片唯一"在一起" |
| bar101 之后 | 逐段收窄 | 她褪色，紫跟着变淡 | 留不住 |
| bar127（226s）| **0** | 粉版几乎抽干 | 空 |

**辅助量具**：她身上粉的浓度 `100% → 88% → 60% → 40% → 20% → 0`，**只降不升**，唯一例外是 bar80 那一下回到 100%（而且那一下马上被黑吃掉，所以观众会怀疑自己看错了）。

### 4.3 这个画风的"运镜"只有六种

> 孔版没有镜头，只有**纸怎么动**。所有"运镜"都是纸或版的动作，不许出现真实的摄影机运动（无景深、无变焦模糊、无手持）。

| 名 | 动作 | 表达的 |
|---|---|---|
| **移纸** | 整张画面平移 8–40px/拍，网点跟着走（网点钉在纸上，不钉在物体上） | 走、路过、时间流过 |
| **推网点** | scale 1.00→1.06→1.30，网点一颗颗长大成形状 | 逼近、看清、进回忆 |
| **抽版** | 一块版在 1 帧里被抽走，画面立刻少一层色 | 断裂、人走、灯灭 |
| **翻页** | 垂直翻，右上角先起，带 3px 纸白投影 | 换场（唯一合法的"转场"） |
| **转纸** | 整张纸旋转 180°，画面上下颠倒 | 只给"返航"用一次 |
| **抖纸** | 套版踢 8–14px，0.25s 带余振回到原位 | 重鼓 |

## 5. 三条硬主线（改稿不许破坏）

### ① 白洞 —— 她的缺席是一个形状

天桥栏杆上有一处 **40% 粉的淡痕**（bar7 第一次出现）。它会被**推网点**放大，变成一个人形白洞（78×150px）。全片这个洞出现 6 次，**尺寸只增不减**：

`淡痕 → 洞 → 洞里有雨 → 手伸进去消失 → 洞长到半屏 → 最后一张纸上洞还在`

**规则**：白洞出现时，画面里**不许有粉**。洞是"没有"，不是"有"。

### ② 粉在耗尽 —— 她的存在是一块会用完的油墨

从 bar34 起，粉版浓度只降不升，伴随针孔（pinhole）逐拍增加：
`100% → 88%(bar34) → 60%(bar40) → 40%(bar87) → 20%(bar122) → 0(bar127)`。
**唯一一次回到 100% 是 bar80 的两拍，而它立刻被墨黑吃掉。**

### ③ 三道保质期刻线 —— 一枚印章砸三次

一枚木章「保质期」+ 三道竖刻线。三次副歌各砸一次，每次划掉一道：

| 次 | 砸 | 划 | 划的人 |
|---|---|---|---|
| 一 | bar52（92.80s）| 第一道，划满 | 他 |
| 二 | bar101（179.09s）| 第二道，划满 | 他 |
| 三 | bar119（211.54s）| 第三道，**划到一半停住** | 她的手按住章，没让砸下去 |

## 6. "全程高能"怎么落地

> 孔版的本性是**克制**。所以高能不能靠加东西，只能靠**"印"这个动作本身**——每一拍都发生一次版面事件。这是本片与 80s 霓虹版在方法论上的根本区别：**那边靠光和粒子堆，这边靠版和纸动。**

### 6.1 十二个事件发生器

| 号 | 发生器 | 触发 | 具体做法 |
|---|---|---|---|
| **R1** | **上墨（gate）** | 每拍 | 一块版的门在某个矩形区域内 1 帧打开，区域从纸白变实心；边缘带一道更重的墨带 |
| **R2** | **套版踢** | 每拍（弱）／重鼓（强） | 弱 2px、强 8–14px，0.25s 带余振回位 |
| **R3** | **滚筒扫** | 换镜／段落 | 一道移动的边＋墨带横过画面，边前是旧景，边后是新景 |
| **R4** | **表情换版** | 每拍 | 眼/嘴在 12fps 上换一张 |
| **R5** | **白洞呼吸** | 每拍 | knockout 形状缩放 0.96–1.04 |
| **R6** | **网点长大** | 每 2 拍 | 网点周期 6→8→11px，形状从点变块 |
| **R7** | **叠印生长** | 大时刻 | 一版的形状长满画面，底下的一切变成混合色 |
| **R8** | **针孔** | 每拍 3–8 颗 | 实心区里出现纸白小点（她的褪色就是针孔变多） |
| **R9** | **进纸痕** | 每小节 | 沿进纸方向一道 2–6% 浓度差的长条 |
| **R10** | **对版十字** | 每 2 拍 | 四角的 ✛ 轻轻转 0.5°／跳 1px |
| **R11** | **纸动** | 每拍 | 整张画面位移 1–6px、旋转 ≤2° |
| **R12** | **形状叠切** | 换镜 | 上一个镜头的某个平涂形状，直接变成下一个镜头的同类形状（圆→灯→印章→雨滴） |

### 6.2 密度表（每拍必须满足）

| 段 | 每拍件数 | 兜底组合 | 额外 |
|---|---|---|---|
| 前奏 bar0–8 | **3** | R1 + R10 + R6 | 开场 3 秒 3 变化 |
| 主歌一 bar9–24 | **3** | R4 + R8 + R11 | 重鼓 → R2 强 |
| 清单段 bar24–34 | **4** | R1 + R4 + R9 + R6 | 每拍必须"上一格" |
| bar34–41 | **4** | R4 + R8 + R2 + R11 | 她的针孔每拍 +1 |
| 副歌一 bar41–56 | **5** | R4 + R1 + R6 + R2 + R9 | 每小节一次 R7 |
| 间奏 bar57–68 | **4** | R11 + R3 + R12 + R10 | 抽纸每拍一张 |
| 桥段 bar68–80 | **4** | R4 + R8 + R2 + R9 | 刮刀每拍一刀 |
| bar80–87 | **5** | R7 + R4 + R2 + R5 + R1 | 全片最强 |
| 副歌二/三 bar87–121 | **5** | R4 + R1 + R2 + R6 + R9 | 套版从 8px 收到 0 |
| 尾声 bar122–130 | **3**（不许低于） | R5 + R8 + R2 | 最后一击 R7 |

### 6.3 三条硬规则

1. **一拍至少 3 件，重鼓叠第 4 件。** 521 拍 × 3 = **1563 个事件**，必须由发生器规则表铺满，不许有"静止拍"。
2. **每个有人的镜头每拍必须换表情**——纸人的脸就是节拍器；不换就是死纸。
3. **不许连续两拍用同一个发生器组合。** 相邻两拍的组合必须有 ≥1 件不同（否则观众会看出循环）。

## 7. 逐段分镜（130 小节 / 53 镜）

> 记法：**编号 · 小节（秒）· 歌词 · 版况 ／ 脸** ／ 画面 ／ **逐拍 b1–b4** ／ 纸怎么动 ／ 注
> 时间一律写 `bar` / `line`，代码里不写秒。
> 「脸」是硬指标：谁、什么角度、什么表情。**没写脸＝没通过。**

---

### P · 前奏 bar0–8（0.00–14.20）· 一张纸开始有东西

**S01 · bar0–1（0.00–1.74）· 无词 · 纸白 ／ 脸：无**
- 画面：纯纸白，带极细的纸纤维。四角逐个落下对版十字（墨黑 2px ✛）。
- 逐拍：b1 左上 ✛ 印上（1 帧）｜b2 右上｜b3 左下｜b4 右下 + **蓝墨从画面下缘滚上来**（R3 滚筒扫，带一道 6px 更重的墨边）
- 纸：不动。**开场不许动，动就输了**
- 注：1.74 秒 4 个动作，满足"3 秒 3 变化"。**第一帧必须是纸，不是黑**——本片没有黑场开场，只有一张白纸。

**S02 · bar1–2（1.74–3.52）· 无词 · 蓝 40% ／ 脸：无**
- 画面：城市从网点里长出来。上半部蓝 40% 网点先是稀点，然后点长大连成天桥的横梁。

## 9. 技术实现

### 9.1 渲染管线（R 版／G 版／B 版三条通道）

1. 每帧画进**一张 RGB 画布，三个通道各是一块版的浓度**（R=蓝、G=粉、B=黄，0=无墨，1=实心）
   - `source-over` ＝**敲白**（真实挖掉下面那块版）
   - `globalCompositeOperation='lighter'` ＝**叠印**（只往指定通道加墨，两版相遇自动出第三种色）
2. 交给 WebGL2 印刷着色器：
   - 每版独立偏移 + 微小旋转 → 套版错位
   - 网点：余弦点函数 + 15° 起的屏幕角，1080p 周期 6–8px，密度 ≥0.9 直接印实
   - 颗粒作用在网点阈值上；实心区扎针孔；沿进纸方向做密度条纹
   - 合成 `纸 × Π mix(1, 墨, 覆盖)`，加纸纤维
   - **网点钉在纸上，不钉在物体上**——移纸时图在固定的网屏下滑动
3. 人物层额外过一遍**纸白晕圈**：先把人物层用 `brightness(0)` 打一圈 4–5px 的环（零墨＝纸），再画人
4. **特效管线**：Playwright 逐帧 PNG → 无损中间片（yuv444p）→ 编码时 `-tune grain`。**不许用 JPEG 4:2:0**，饱和网点会被抹成髒斑

### 9.2 性能与节奏预算

| 项 | 设定 |
|---|---|
| 帧率 | 24fps（人物 12fps，印刷事件 24fps） |
| 每帧版面事件 | 3–5 件，用规则表生成，不逐帧手写 |
| 事件表 | 导出 CSV：`拍号, 秒, 帧, 发生器, 参数, 角色, 表情`，521 行 |
| 缓存 | 五张场景底板画一次存 1.5×，推网点不糊 |
| 最贵的帧 | S35（三版全叠 + 裂缝）、S31（纸片满屏）——单独预渲染验证 |

1. **结局那颗 1px 粉点留不留？** 我建议留——它是"趁你还愿意"唯一的物证。去掉就是纯悲观。
2. **她的褪色要不要解释？** 我建议**不解释**（不给她得病/搬走的线索），让"油墨会用完"自己说话。
3. **配角用几个？** 现在 4 个（老周、小豆）。小豆目前只在 S13 冷柜背景里出现 2 拍，要不要给他一个独立镜头？
4. **字幕全上还是只上金句？** 全上更安全；只上 12 句金句会更"艺术片"，但抖音端会掉完播。
5. **47 秒间奏走"纸堆"还是"折纸船"？** 纸堆（现方案）更狠、更贴"三年"；折纸船更美、更贴"流浪"。二选一。
