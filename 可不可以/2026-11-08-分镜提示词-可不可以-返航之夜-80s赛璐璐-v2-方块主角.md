## 0. v1 → v2 修订（两件事）

| # | v1 的做法 | v2 改成 | 为什么 |
|---|---|---|---|
| 1 | **人物按 80s 写实比例重画**（长蛋脸、杏仁眼、6 头身） | **一律用资产库方块主角**：方脸 34×34、头发盖顶、方块卫衣、两条短腿穿鞋，3 头身 | 用户裁定：人物必须是资产库里的方块主角 |
| 2 | **阿岩正脸全片只给 6 次**，小粉只给侧脸/倒影/3px 粉影 | **每个有主角的镜头都必须露脸**。阿岩正脸 ≥40 镜，小粉露脸 ≥18 镜；背面全片 ≤6 次且必须同镜转侧脸 | 用户裁定：不能人脸都不露 |

**连带改动**：小粉在"现在的时空"里从"只存在于反光"改成"**实体在场**"——她在食街帮老周、在便利店值夜、在天桥那头等。**她一直没有离开这座城**，只是他每次都晚一步。这条改完，副歌三连才有东西可演，结局的"回头"也才站得住。

## 1. 一句话

**他在一夜里走回一座城市，她一直在这座城里，两个人隔着 20 米、10 米、3 米，一次比一次近，谁也没先迈那一步。**

他当年说好带她去流浪，半路一个人回来了。今晚他回来了——不是回这座城市，是回**这一条街**。城市比人走得快：车、扶梯、霓虹、雨，全都比他快。只有一处为他停下来：天桥。

**方块主角白送的三件事**：

1. **脸是整块画布**：方脸上没有鼻梁和颧骨挡着，一个眼神高度、一个嘴型，情绪就是全屏的。竖缝眼一收一放，比写实脸快三倍。
2. **表情靠"换版"不靠"过渡"**：8fps 换一张，天然是赛璐璐的步进节奏——高能段落里，表情换版就是鼓点本身。
3. **方块会"整块"动**：squash / stretch / 整体倾斜 / 整块跳，比关节动画更适合卡点；一个人可以在一拍里从"站着"变成"整个人歪过去"。

## 2. 画风卡（硬约束，不许改）

> 从 `styles/cel-anime-80s/STYLE.md` 抄成施工条款。违反任意一条，画面立刻从"80s OVA"掉成"现代数字动画"。

### 2.1 四层，缺一层就不是这个画风

| 层 | 做法 | 本片用在哪 |
|---|---|---|
| **① 手绘背景板** | 开机画一次：喷枪渐变、发光的窗、湿地反光；再存一张**发光副板（emissive）**，两张一起平移 | 站前街、食街、便利店、天台、天桥 |
| **② 赛璐璐 cel** | 平涂 + **硬边**阴影月牙 + **硬边**高光月牙 + **彩色**轮廓线（**永不用纯黑**） | 阿岩、小粉、老周、小豆、车、伞、关东煮 |
| **③ 逆光（透過光）** | 招牌、路灯、字幕、霓虹**穿过**画面发光；光斑、光晕 | 全片夜景；副歌三连加倍 |
| **④ 磁带 + CRT** | 色度溢出、扫描线、RGB 栅格、荧光拖影、四角压暗、细噪点 | 全片，字幕在这一层里合成 |

**判据**：一帧如果看起来像"现代数字动画"，一定是少了 ③——方块 cel 上没有那道饱和霓虹**轮廓光（rim 2–4px）**。

### 2.2 方块主角画法（v2 核心）

> 尺寸是"单位"，全高 100 单位 = 画面上 s 像素（`s` 就是身高像素）。3 头身。

| 部件 | 规格 | 说明 |
|---|---|---|
| **方脸** | 34 × 34，圆角 7，肤色三色（亮 / 暗 / 线） | 脸的**上半部被头发盖住**，露出来的是一块完整的"脸板" |
| **眼** | 两道**竖缝**：宽 3.0、高 6.4，圆角 1.5，色 `#2A2E36` | 睁大 = ×1.25；眯 = ×0.55；闭 = ×0.18；**笑 = 换成弯眼（一道上弧）** |
| **高光** | 每条竖缝左上角一颗 1.2 半径白点 | 只在睁眼时画；**这是它"活着"的唯一证据**，不许省 |
| **嘴** | 一条 5.2 宽的线 | 平（默认）/ 上弧笑 / 大开口 / 下撇（委屈）/ 一字（咬牙）|
| **腮红** | 两块 4.2×2.2 椭圆，透明度 .26 | 只在"羞 / 笑 / 气"时出现，**不许常驻** |
| **头发** | 盖顶：从 -107 罩到 -88，刘海 7 个尖，最低 -96.8 | 发型四种：短发 `short` / 双丸子 `buns` / 寸头 `buzz` / 爆炸 `afro` |
| **天使环** | 一条 12.6 半径的弧，亮度 .8 | 阿岩、小粉必有；老周没有（寸头） |
| **躯干** | 32 × 29 圆角 5.5 的方块卫衣 + 兜帽弧 + 两根抽绳 + 口袋线 | 颜色 = CAST 的 `cloth`，暗面 `clothDk` |
| **手臂** | 从 (±16.4, -61) 出发，长 19，宽 9.6 | 末端是 **10.4×9.6 的肤色小手块**（这是手，不是球） |
| **腿** | 两条，宽 11.4，从 -38 到 -7 | 摆动 ±7 单位就是一步 |
| **鞋** | 15.4 × 8.4，圆角 3.4 | 小粉的白鞋是她的 accent，夜里反光 |

**线条**：全部 `line` 色（深一档的服装色 / 深褐肤色），宽 **2.2–2.6px**；特写里收到 2.0px，**不许加粗**。线是赛璐璐的骨，粗了就变成贴纸。

### 2.3 表情系统（8fps 换版，每拍至少换一次）

| 名 | 眼 | 嘴 | 附带 | 用在哪 |
|---|---|---|---|---|
| `calm` 平静 | 竖缝 1.0 | 一字 | — | 默认 |
| `blink` 眨眼 | 0.18 | 一字 | — | 每 3–4 拍必有一次（不然像死的） |
| `wide` 睁大 | 1.25 | 一字 | 高光变大 | 车灯点名、看见她 |
| `smile` 笑 | 弯眼 | 上弧 | 腮红 .26 | 回忆段、她在场 |
| `laugh` 大笑 | 弯眼（更弯） | 大开口 ×1.6 | 腮红 + 头后仰 | S25 她的笑 |
| `sad` 委屈 | 0.7 | 下撇 | 眉压 | 自责、看不见她 |
| `grit` 咬牙 | 0.8（压扁） | 一字加粗 | 下颌线加深 | 跑、冲门 |
| `shock` 愣 | 1.25 + 高光偏移 | 小开口 | **emote：闪电/汗** | 副歌重拍 |

**emote 符号**（画在头顶右上方，跟节拍弹）：`汗`（三条弧）、`心`（两颗，副歌专用）、`星`（四角星，惊喜专用）、`雷`（闪电，冲击帧专用）。**同一镜头最多一个**，多了就变成表情包。

### 2.4 露脸规则（硬，写进检查脚本）

| # | 规则 | 量 |
|---|---|---|
| 1 | **每个有主角的镜头，必须至少 1 拍能看到完整脸**（正面或 3/4，眼睛高光可见） | 67 镜逐个查 |
| 2 | **阿岩露脸 ≥ 40 镜**；其中**正面 ≥ 18 镜** | 数 |
| 3 | **小粉露脸 ≥ 18 镜**；正面 ≥ 10 镜（含回忆段与现在时空） | 数 |

| 5 | **纯剪影只给群演**。主角可以逆光，但**眼睛必须看得见**（逆光时用一颗亮高光破剪影） | 逐帧看 |
| 6 | 表情每拍换一次版；**同一表情连用不超过 2 拍** | 逐镜看 |

### 2.6 节奏

| 元素 | 帧率 | 说明 |
|---|---|---|
| 人物身体/姿势 | **12fps**（on twos） | 整块位移、倾斜、蹲下，都在 12fps 网格上 |
| 表情（眼/嘴/高光/emote） | **8fps**（on threes） | 三张一换，绝不插值 |
| 镜头、光带、泛光、雨、车流 | **24fps**（on ones） | 镜头一抖就穿帮 |

- **"移动光，不移动画"**：彩色光带在**静止的方块**上扫过（`source-atop`）。
- **冲击帧**：2 帧反相或单色剪影 + 放射线，然后接结果。
- **守住峰值**：全片允许 **3 处**静帧（S10 水下、S40 线稿、S67 结尾）。
- 硬切切在小节头；转场只用：硬切、闪白、冲击帧、磁带撕裂。**不许溶解、不许划像。**

### 2.7 镜头语法

| 运镜 | 表达 | 用在哪 |
|---|---|---|
| 多层横移（3–4 层视差） | 稳定推进 | 沿街走、跑、食街全景 |
| 高板摇臂升降 | 世界一层层揭开 | 站前广场、天桥俯瞰 |
| 背影进伪 3D 峡谷 | 速度、前方有压迫 | 扶梯、天桥阶梯 |
| 停住的半身 + 光带扫过 | 有速度感但不画动画 | 地铁抓吊环、等灯 |
| **方块脸插入镜** | 这个表情重要 | 全片大量使用（方块脸近景最稳） |
| 眼极特写 | 决心、认出 | S59、S66 |
| 慢摇过一张静帧 | 屏息、记忆 | S10、S40 |
| 放射速度线 + 一拍冻结 | 撞击前的一瞬 | 副歌起跳、冲门 |

### 4.3 城市作为第二演员的三条规则

1. **城市永远比人快**：车流、扶梯、霓虹、群演，一律比他快一档。他越急，城市越快。
2. **城市替他们让路**：两个人靠近时，人潮会自动分开一条缝——但缝只开一拍，然后合上。
3. **城市只在一处停下**：从 **bar122** 起，所有动态元素速度降到 **0.25×**，只有雨正常下。

## 5. 三条硬主线（改稿不许破坏）

### ① 红发圈：口袋 → 手心 → 指上 → 举起 → 留下

| 次 | 位置 | 时间 | 状态 |
|---|---|---|---|
| 1 | 口袋露一角 | S06 · bar7 | 只看得见 3px 的红 |
| 2 | 天台地上 | S44 · bar77 | 落在地上，两个人同时去捡 |
| 3 | 套在食指 | S49 · bar87 | 副歌二起手，像戒指又不是戒指 |
| 4 | 掏出、套上 | S62 · bar114 | 正面、两只手、8fps 三张 |
| 5 | 举起来 | S65 · bar119 | 对着 3 米外的她 |

> 第五次之后**不再出现**。她回头，发圈还在他手上——**这个不确定就是结局**。

### ② 三次副歌 = 同一组镜头，三次重印，每次多一张脸

| | 段 | 机位 | 变了什么 |
|---|---|---|---|
| **一** | bar40–56（71s） | 基准版（S27–S34） | 城市亮的，两个人在同一座城里，**隔着 20 米** |
| **二** | bar87–103（156s） | **机位/构图一个不动**（S49–S55） | 每个镜头里**她的脸更近一档**（20m → 10m）；他手上多了发圈 |

### ③ 距离递减：20m → 10m → 3m → 0（但谁也没迈步）

| 段 | 距离 | 画面上就是 | 脸有多大 |

## 6. "全程高能"怎么落地

### 6.1 十二个事件发生器

| 号 | 发生器 | 触发 | 具体动作 |

## 8. 字幕

- **位置**：底部往上 96px，居中，**不挡脸**（所有脸都留了下部空间）。
- **字**：**华文楷体 STKaiti**，**72px**，奶油黄 `#F7E9C4`，描边 4px 深褐 `#3A2A22`，柔阴影 6px，字距 4px。
- **合成层**：字幕在**磁带层之内**（跟画面一起吃扫描线和色度溢出）——它是"录像带上本来就有的字"。
- **时序**：逐字时间来自 `song.json`。淡入在开唱前 **0.10s**，唱完 +0.25s 淡出。换句时前一句立即让位，不叠加。
- **一句一行**，不折行。最长「只是刚好情窦初开遇到你」11 字 × 72px ≈ 792px，安全。
- ⚠ **待定**：`line47「趁你还愿意」` 强制对齐是 **220.96–221.68（0.72s）**，但 LRC 给的是 220.97–227.69（6.7s），音乐里这句确实拖了长音。**建议**：字在 221.0 全部上屏，保持到 227.6 再淡出。这一条需要点头。

## 9. 技术实现

```
可不可以/
├── mv2-listen/          song.json / song.md / songmap.png / audio.wav（只读）
├── cel/                 index.html / render.mjs
│   └── src/             util.js（色模型·雨·湿地）cel.js（月牙上色）people.js（方块人物）
│                        city.js（五个场地）post.js（泛光·CRT·字幕）scene.js（67 镜）
└── out/                 stills/  mv_草稿.mp4  mv.mp4
```

| 要做的事 | 怎么落 |
|---|---|
| 方块人物 | `people.js`：方脸 34×34 + 头发盖顶 + 32×29 卫衣 + 两腿穿鞋，全高 100 单位 |
| 表情 8fps | `step = Math.floor(t*8)/8` 取表情索引；**姿势走 12fps**，两套 step 分开 |
| 赛璐璐上色 | 离屏画平涂 → 阴影月牙（multiply）→ 高光月牙（screen）→ 逆光轮廓（lighter 2–4px） |
| 五套色模型 | `util.js` 五组常量；`RED = #E23A2E` 不参与乘色 |
| 背景板 | 每个场地开机画一次（colour + emissive 两张），之后只平移；湿地 = 翻转模糊拉条 |
| 泛光 | emissive 画布降采样 + blur + `lighter` |
| CRT | 色度溢出 + 扫描线 + RGB 栅格 + 四角压暗 + 噪点 + 字幕（同一层） |
| 确定性 | 随机一律 `hash(i)` / `rng(seed)`，**禁止 `Math.random()` 和 `Date`** |
| 字体 | `document.fonts.load('500 72px STKaiti')`，加载完再画 |

**渲染**：`node render.mjs --stills=…` 出静帧；`node render.mjs --video --fps=24` 出全片。
