## 0. 为什么是半调案卷

这首歌的语法是**申请**：四句「我可以……」，五句「可不可以」，最后落在「趁我还没有过保质期」。
申请就要有表格，表格就要有栏位、编号、附件、有效期、钢印。

**而这份表格他填了三年，没法交上去。**

半调案卷这个画风白送三件事：

1. **章 = 节拍器。** 风格里最狠的动作就是"钢印砸下来"。820 个底鼓不需要找动效——**章落就是底鼓**，纸面凹下去、油墨边缘毛一圈、镜头抖一下，三样同时发生。
2. **网点 = 情绪表。** 网点密度是这个画风唯一允许的"渐变"。她出现的时候网点往外炸开，快要失去的时候网点从边缘往里挤，把画面挤窄。
3. **官僚纸张 = 时间的形状。** 页码、案卷号、受理日、有效期、过期天数——这些数字全是拍点。它们每跳一格，就是一拍。

**这座城市不是背景，是证物。** 便利店的小票、地铁的票根、天桥上的雨、洗衣店的取衣单——每一件都被编号、被别在卷宗上、被红笔圈过。他要证明的事只有一件：**三年前这里丢过一件东西，现在还在。**

## 1. 一句话

**他拿着一份《遗失物认领单》，到城市的办事窗口去认领一件 2019 年丢的东西；窗口盖了三次章——受理、补正、过期；最后一次章落下去，纸被抽走了。**

不是"他回城里找她"，是**他在为一件"人"办手续**。城市负责给这件事编号。

## 2. 画风卡（硬约束，违反任意一条就不是这个画风）

来源：`styles/halftone-dossier/STYLE.md`。借画法，不借它的故事、案件、版式、道具。

### 2.1 六条材质纪律

| # | 纪律 | 违反的后果 |
|---|---|---|
| **M1** | **整部片是一张纸。** 米黄档案纸 + 低频斑驳 + 细颗粒 + 暗角 + 一道折痕；夜场也印在这张纸上，**不许发光** | 立刻变成"深色 UI"，不是印刷品 |
| **M2** | **明暗不许用渐变**，只用网点：两到三层不同网角的点相乘叠加。网点 **step 20–26px**，`k` 0.6–0.72 | step < 14px 编码后起摩尔纹，满屏水波 |
| **M3** | **人物和手绘道具才有 line boil**（约 5px 扰动、10 次/秒重播）。**文字、网点、HUD、caption 条一律不 boil** | 字糊成一团，网点变沙 |
| **M4** | **一套头 通用于所有身体**：粗墨线 ~7px、平涂、脸/腹一块提亮、亮眼（墨椭圆 + 两道高光）能眯/眨/弯成弧 | 每个镜头一张新脸 → 不是同一个角色 |
| **M5** | **一切进场都带过冲**（back ease，0.3–0.45s），从画面下方升起或从 0 放大。**不许淡入** | 全片变幻灯片 |
| **M6** | **只许硬切和网点擦除**，没有叠化、没有溶解 | 印刷品不叠化 |

**固定种子**：所有网点相位、颗粒、boil 由 `(镜号, 对象id, 帧号)` 算出，同物体跨帧不许"沸腾"。

### 2.2 色逻辑：纸 + 五色墨

| 名 | 值 | 只负责 | 纪律 |
|---|---|---|---|
| **纸** | `#F2E8D5` | 底、留白、"没写的地方" | 全片出现面积最大，它才是主角 |
| **主墨** | `#1B2A44` | 所有描边、正文、caption 条、淡出色 | 偏蓝的黑，永远不是中性黑 |
| **套印红** | `#D4482F` | 套印偏移影、章、红笔圈注、警报 | **章只用这个红**，别处用要克制 |
| **高亮黄** | `#F2B705` | 关键词、数字、日期、屏幕光 | 只做"被指出来的东西" |
| **城市青** | `#2F7E8A` | 夜街、玻璃、地铁、雨 | 夜场的第二层网点 |
| **她（满纯粉）** | `#E8748E` | **只有她的痕迹**：名字、签字、指印、一根头发 | **全片唯一满纯度色。别人身上不许出现** |
| **深墨底** | `#0E1626` | 关灯的厅、隧道、抽空帧 | 深，但仍是纸上的深（要看得见网点） |

**两条铁律：**

1. **满纯粉 = 她亲手留下的痕迹**。她的粉卫衣在案卷里只能印成**网点粉**（30% 密度，粉色点阵），绝不许实心。所以她每次"变实"都发生在名字和签字上——**名字比衣服更真实**。
2. **红只属于官僚与判决**：章、红笔、退回、过期。他手里的笔永远是主墨色——**他没有权力用红**。

### 2.4 人物：从资产库 human 到"粗线案卷人"

> 资产库是 3 头身方块小人（肤色方脸 + 两条腿 + 小躯干）。半调案卷要把它**印出来**：不换比例、不换骨架、不换情绪系统，只换"怎么落墨"。

| 部位 | 资产库原样 | 本片做法 |
|---|---|---|
| **轮廓** | 2–3px 墨线 | **7px 硬墨线**（1080p 定值），线宽不随缩放变；线段有 12–25% 断口 |
| **填充** | 单色平涂 | 平色 + 一块提亮的"脸/腹"区；**阴影是网点**，不是深色块 |
| **眼** | 椭圆 + 高光 | 墨椭圆 + **两道高光**（一大一小），能眯（压扁 0.3）、能眨（0.08s）、能弯成弧（笑） |
| **嘴** | 线 | 6 种：横线 / 上弧 / 下弧 / O / 波浪 / 咬牙（竖线格） |
| **头发** | 平涂 + 描边 | 3–5 块硬边形状，**网点压在发根**（越靠近头皮越密） |
| **服装** | 平涂 | 平色 + 一处网点（袖口/胸口），衣褶用 2 根短墨线 |
| **boil** | — | **只在人物和手绘道具上**，10 次/秒换一次扰动种子 |
| **尺寸** | 3 头身 | 中景身高 ≈ 400px，特写脸 ≈ 300px（此时线宽仍 7px，墨线会显得更重——这是故意的） |

**两条动作约束：**
- 人物身体走 **12fps（on twos）**，用整块 squash/stretch + 倾斜，不做关节动画；
- **网点、字、章、纸、镜头走 30fps（on ones）**。人比印刷慢半档——这个不同频就是"活人印在纸里"的感觉。

### 2.5 表情系统（每拍换一次，8fps 换版）

沿用资产库 31 种情绪，但只允许其中 **14 种**（粗线 + 大眼能读的）：`neutral happy excited laugh love shy sad cry angry surprised confused thinking determined hopeful`。
每个情绪 = 眼（形状+高光位置）+ 嘴（6 种之一）+ 一处附加（眉毛/汗滴/闪光/竖线）。

| 情绪 | 眼 | 嘴 | 附加 | 用在哪 |
|---|---|---|---|---|
| `neutral` | 墨椭圆，高光偏上 | 横线 | — | 填表 |
| `thinking` | 上眼睑压 20% | 横线偏左 | 一个问号网点 | 写字卡住 |
| `determined` | 眼睛压扁 25% | 咬牙（竖线格） | 眉压低 | 决定回去 |
| `sad` | 眼尾下垂 | 下弧 | 一道竖网点从眼下流下 | 你已不在原地 |
| `hurt` | 半闭 | 波浪 | 一根断线 | 被退回 |
| `excited` | 大眼 + 双高光 | O | 星芒 8 角 | 附件上桌 |
| `hopeful` | 上抬 | 上弧小 | 头顶一圈淡网点 | 递表 |
| `confused` | 一只大一只小 | 波浪 | 两个问号 | 章悬在头上 |
| `cry` | 弯成下弧 | 下弧张开 | 两道网点泪 | 章砸空 |
| `laugh` | 弯成上弧 | 大开 | 三颗星 | 第一次受理 |
| `shy` | 斜看 | 小上弧 | 脸侧网点加深 | 写"她" |
| `angry` | 压扁 + 眉 | 咬牙 | 竖线 | 抢笔 |
| `surprised` | 大眼 + 高光缩 | O | 三根放射线 | 纸被抽走 |
| `love` | 眼弯 + 高光心形 | 上弧 | 两颗小星 | 只看一次：结尾 |

### 2.6 字幕：说明条（caption bar）

- **形式**：深墨药丸条 `#1B2A44` + 套印红偏移影（+4/+4px，multiply）+ 纸色字 + **关键词高亮**（黄，或她的名字用粉）。
- **入场**：**打字机**——每个字在它自己的逐字时间上"打"进来（字从上方 30px 落下压扁，0.06s；stagger 0.02s；打完留一个 1px 墨点）。
- **停留**：≥ max(1.8s, 唱完 + 0.6s)。换句用"抽纸"或直接硬切。
- **位置**：底部中央，宽 ≤ 画面 78%，底距 96px；**HUD 在四角，不许和字幕抢**。
- **金句**（第 24/25/36/37/44/45/46/47 句"趁我还没有过保质期 / 趁你还愿意"）：**不做 caption 条，升级成整屏大字**（见 §9），字被章压着。
- **不做卡拉OK 逐字填色**——这个画风的字是"印上去的"，不是"被唱亮的"。逐字只做"打进来"。

### 2.7 节奏分层（三个层次同时跑，缺一层就不叫高能）

| 层 | 单位 | 内容 | 谁在动 |
|---|---|---|---|
| **L1 拍层** | 0.4445s | 一个"主动作"：章、字、纸、脸、镜头其一 | 主体 |
| **L2 半拍层** | 0.222s | 一个"次动作"：网点呼吸一档、纸角弹一下、高光移一格 | 背景/材质 |
| **L3 底噪层** | 每帧 | 网点相位 0.3px 漂、颗粒 300 点重播、HUD 毫秒位跳 | 全画面 |

### 2.8 镜头语法（只用这 8 种）

| 招式 | 表达 | 用在本片 |
|---|---|---|
| **锁定正视 + 0.6% 拍脉** | 这是一张海报/一页表 | 填表、受理、签字 |
| **慢推（1→1.06）** | 审读、要判了 | 章抬起时、附件被翻 |
| **二次衰减抖（5–26px）** | 撞击 | **每次盖章**、纸被抽走 |
| **闪帧（≤0.5 白，2 帧反相）** | 被拍下来、被判定 | 5 个大时刻 |
| **沿红笔线横移** | 顺着一条"注释"看下去 | 划掉的"半路"、圈注 |
| **snap zoom 进网点** | 看仔细 | 章印、指纹、过期日、结尾那个点 |
| **翻页 / 抽纸** | 下一页、下一章 | 段落切换、附件翻 |
| **拉远露出整张桌面** | 这只是一份卷宗 | 间奏、结尾 |

**构图**：大字左上，主体右侧偏中，caption 条底部居中，HUD 两角。**页码永远在右下**（`P.023 / 047`）。

## 4. 世界观：一份卷宗 = 一座城市

### 4.1 五个场地（一套纸墨模型对一个）

| 场地 | 模型 | 城市功能 | 出镜段 |
|---|---|---|---|
| **政务大厅 3 号窗口** | `D-DAY` / `S-STEEL` | 给事情编号的地方 | 全片 |
| **候号区 + 叫号屏** | `D-DAY`（暗一半） | 等待 = 时间被别人的号码占用 | 间奏 |
| **便利店（夜）** | `N-STREET` | 保温柜、关东煮、玻璃门上她的手印 | 主歌一 |
| **天桥 / 雨街** | `N-STREET` | 车灯、竖条网点、湿地面 | 主歌一、副歌二 |
| **拍立得里的 2019** | `P-2019` | 夏天、汽水、她 | 附件、结尾 |

### 4.2 时间标尺（全片的隐形时钟）

- **案卷号** `KB-2019-0703`：2019 年 7 月 3 日，他们开始的那天。
- **受理日** `2026.11.08`：他今天来办（就是今天）。
- **有效期至** `2022.07.03`：分开那天。**已经过期 4 年 4 个月 5 天。**
- **HUD 右上角**：`EXPIRED 4Y 04M 05D 06:12:33`，**秒位每拍跳一次**（不是真秒，是拍秒）。全片它一个数都不减。

> 这个时钟是"高能"的第四层：观众不一定读得出来，但**画面里永远有东西在往上涨**。

### 4.3 "城市作为第二演员"的三条规则

1. **每次他情绪掉下去，城市就多一件东西挡住他**：门、柱子、别人的背、一辆横穿的车。
2. **城市的所有数字都比他大**：叫号屏是 048，他是 047；保质期是 2022，他是 2026。
3. **拍立得里的 2019 是唯一没有 HUD 的画面**——时间在那里面停了。

## 5. 三条硬主线（改稿不许破坏）

### ① 页码：`P.001 → P.047`，只有一处回退

- 每句歌词 = 一页。页码在右下角，**主墨色，JetBrains Mono 800**。
- 页码不是"装饰"，是**卡点**：换页 = 一次抽纸（0.44s，正好一拍）。

### 6.3 三条硬规则

1. **一拍至少一件，重鼓叠第二件。** 521 拍 / 820 底鼓 = 平均 1.57 底鼓/拍，所以**一半的拍要放两件**。

## 13. 已知风险与待核

### 13.1 画风风险

1. **网点 ≠ 滤镜**。最容易犯的错是把整张画面套一层网点贴图。必须是"密度场 → 点径"，阴影的边要能被点数出来。
2. **章太多会腻**。全片只有 3 次真章 + 1 次砸空 + 1 次笔点。中间那些"像章"的东西（圆角框、编号块）不许做成章的质感。
3. **纸不能太干净**。每一帧都要有 300 点颗粒 + 暗角，否则就是"矢量图加了点"。

### 13.2 数据待核（必须回原曲听）

- **L47「趁你还愿意」**：220.96 之后四个字全在同一时刻（221.68）。
- 其余 44 句的对齐可信（±80ms）。
